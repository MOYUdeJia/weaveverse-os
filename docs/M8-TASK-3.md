## 2. 第一块：修图片库 bug

### 2.1 相册 UI 随主题

检查图片库所有组件（PhotoLibraryPanel、AlbumTab、PhotoCard、大图查看器、重命名输入框、多选工具栏、toast）的颜色是否用了**主题 CSS 变量**。切换主题时，全部跟着变。

**不引入新颜色**。用现有主题变量。

### 2.2 多选："移动"弹层加取消键

**现状**：多选后点"移动" → 弹出相册列表 → **没有取消按钮**，只能点某个相册或点外部。

**要求**：
- 弹层加"取消"按钮
- 点击弹层外部关闭
- Esc 关闭

### 2.3 多选：操作后自动退出

**现状**：移动/删除完成后，右上角"完成"按钮还在，需要手动再点一次。

**要求**：移动/删除完成后，**自动退出多选模式**，回到普通浏览。

### 2.4 统一成功提示

**现状**：移动/删除没有成功提示。

**要求**：
- 复用阶段 2 已建的 `frontend/src/toast.js`
- 统一风格，随主题变
- 提示文案："已移动 N 张到「XXX」相册" / "已删除 N 张图片"
- 2 秒后自动消失

### 2.5 大图查看器优化

**现状**：UI 丑。

**要求**：
- 图片**左右两侧加 `<` / `>` 箭头**，可点击切换上一张/下一张
- **鼠标滚轮缩放**图片
- 缩放后拖动平移（拖拽）
- 双击图片 → 还原缩放
- Esc 关闭
- 底部：文件名、保存到本地按钮

**保留现有**：全屏铺满、左右键切换、不拉伸。

### 2.6 重命名改造

**现状**：名字是输入框，直接改，不知道成功没。

**要求**（文件重命名风格）：

**大图查看器里**：
- 显示文件名（普通文本）
- 点击名字 → 变成输入框
- 回车 或 点确定 → 退出编辑 + toast "已重命名"
- Esc 或 点取消 → 退出编辑，不保存

**网格 / 列表里**：
- 默认显示名字（普通文本）
- **双击名字** → 进入编辑（鼠标悬停文字显示提示"双击重命名"）
- 或 **右键 → "重命名"**
- 或 **名字旁小铅笔图标**
- 以上三种你**选一个**，说明理由

**关键**：改名成功后 toast "已重命名"，不要静默。

## 3. 第二块：AI 聊天助手基础

### 3.1 多模型架构

**设计**：支持多个 AI 提供商，用户可切换。

**M8 阶段 3 先接 DeepSeek**，架构预留：
- OpenAI
- Anthropic
- 未来可加

**接口抽象**：
- 统一接口 `chat(messages, model, stream)` → 返回流
- 每个提供商一个 adapter
- DeepSeek 的 adapter 用 OpenAI 兼容格式（`base_url` 改成 DeepSeek 的）

**说明**：DeepSeek 提供 OpenAI 兼容 API，所以 adapter 可以复用。

### 3.2 AI 设置页

**位置**：设置里加一个"AI" Tab（或子页）。

**字段**：
- 提供商：[DeepSeek ▼]（下拉）
- Base URL：（自动填，可改）
- API Key：（密码输入框，保存进系统钥匙串）
- 模型：[deepseek-chat ▼]
- [测试连接] 按钮 → 调一个简单请求验证

**Key 存储**：
- 存 Windows Credential Manager
- 目标名：`weaveverse-os/ai/{provider}`
- 复用阶段 2 的凭据管理代码（`album_lock.py` 里已有的）
- 如果凭据 API 失败 → 退回 `backend/data/ai_secrets.json`（已 `.gitignore`）

**绝对不要**：
- 不要硬编码任何 Key
- 不要在日志里打印 Key
- 不要把 Key 存数据库
- 不要把 Key 写进任何 `.md` 文件

### 3.3 聊天界面

**入口**：左侧栏底部一个 **AI 图标**（🤖 或类似）。

**交互**：
- 点击 → 展开聊天浮层（右侧滑出或底部弹出，你判断）
- 浮层里有：
  - 消息列表（用户/AI 气泡）
  - 输入框 + 发送按钮
  - 顶部：当前模型名 + 关闭按钮
- Esc 关闭浮层
- 快捷键 `Ctrl+J` 呼出（你判断，可换）

**不做**：
- 不做历史会话保存（M9）
- 不做多会话切换（M9）
- 不做对话导出

### 3.4 流式输出

**后端**：`POST /api/ai/chat` → SSE 流式返回
- 前端用 `EventSource` 接收（注意 POST 不能用 EventSource，用 `fetch` + `ReadableStream`）

**前端**：逐字显示，不用等整个回复。

**错误处理**：
- 未配置 Key → 提示"请先在设置里配置 API Key"
- Key 无效 → 提示"API Key 无效，请检查"
- 网络错误 → 提示"网络错误，请重试"

### 3.5 系统提示词

给 AI 一个默认身份。内容：

```
你是 Weaveverse OS 的个人数字空间助手。
你的角色：帮助用户整理思路、回答问题、查找信息。
你的语气：友好、简洁、不啰嗦。中文优先。
你的能力边界（M8 阶段）：你只能聊天，不能操作用户的数据。
未来会支持：帮用户创建页面、搜索笔记、总结内容。
不知道的就说不知道，不要编造。
```

**M8 阶段 3 不让 AI 操作数据**。这只是纯聊天。

### 3.6 依赖

**后端**：
- 用 `httpx` 或 `httpx-sse` 调 AI API
- 不需要官方的 OpenAI SDK（避免重依赖）

**前端**：
- 不需要新库
- 流式用原生 `fetch` + `ReadableStream`
