## 第一部分：语音

### 1.1 语音识别（STT）

**目标**：用户按住某个键说话 → 转成文字 → 填到聊天输入框。

**技术选型**（你判断，说明理由）：
- **faster-whisper**（Python 包，模型自动下载）
- **pywhispercpp**（Whisper.cpp 的 Python 绑定）
- **whisper.cpp 命令行**（子进程调用）

**要求**：
- 默认用 **base 或 small 模型**（平衡速度和精度）
- 首次使用提示"正在下载模型"（首次会下载 ~150MB）
- 模型缓存在 `backend/data/whisper_models/`
- 支持中英文

**交互**：
- 聊天浮层里加一个麦克风按钮
- 按住 → 录音 → 松开 → 识别 → 文字填入输入框
- 或点击开始/结束（你选）

**不做**：
- 不做实时流式识别（那段太复杂）
- 不做唤醒词（M9+）
- 不做多语言自动检测（默认中文/英文）

### 1.2 语音合成（TTS）

**目标**：AI 回复可以用语音朗读。

**技术选型**：
- **edge-tts**（Python 包，免费、微软神经语音）

**要求**：
- 每条 AI 消息旁边一个"朗读"按钮
- 点击 → 生成音频 → 播放
- 可停止
- 默认中文语音（如 `zh-CN-XiaoxiaoNeural`）
- 设置里可换语音

**不做**：
- 不做自动朗读（避免打扰）
- 不做语音克隆

### 1.3 设置

AI 设置页加语音相关：
- STT 模型大小（base / small / medium）
- TTS 语音选择（下拉）
- TTS 语速（滑块）

## 第二部分：私有云（Tailscale）

### 2.1 后端适配

**Tailscale 本身由用户手动安装**，agent 只做应用层适配。

**要求**：
- 检测本机 Tailscale 是否安装、是否登录
- 显示本机 Tailscale IP（如 `100.x.x.x`）
- 后端监听 `0.0.0.0:8765`（而不仅是 `127.0.0.1`），允许 Tailscale 网络访问
- 提供"远程访问"设置页：
  - 状态：已连接 / 未安装 / 未登录
  - 本机 Tailscale IP
  - 手机端访问地址：`http://<tailscale-ip>:8765`
  - 二维码（方便手机扫码）
  - 一键复制地址

### 2.2 安全

- **不修改** Tailscale 配置，只读取状态
- 不做 Passkey（M9+）
- 不做 HTTPS（Tailscale 本身加密传输）

### 2.3 用户操作文档

在设置页显示：
1. 访问 `tailscale.com` 注册
2. 本机安装 Tailscale 客户端
3. 手机也安装 Tailscale + 登录同账号
4. 手机浏览器打开显示的地址

**agent 不代用户注册，只做引导。**

## 第三部分：加密备份

### 3.1 数据导出

**要备份的内容**：
- `backend/data/weaveverse.db`（数据库）
- `backend/data/attachments/`（图片附件）
- `backend/data/books/`（书籍）
- `backend/data/music/`（音乐）
- `backend/data/icons/`（图标）
- `backend/data/backgrounds/`（背景）
- `backend/data/appearance.json`（外观配置）
- `backend/data/quick_tags.json`（常用标签）
- `backend/data/ai_settings.json`（AI 配置，不含 Key）

**不备份**：
- `whisper_models/`（太大，可重新下载）
- 系统钥匙串里的 Key（自动跳过）

### 3.2 打包 + 加密

**流程**：
1. 把上面内容打包成一个 zip（临时文件）
2. 提示用户输主密码
3. 用主密码加密（算法：**Argon2id 派生密钥 + AES-GCM**）
4. 输出 `.wvbak` 文件（Weaveverse Backup）
5. 提示用户选择保存位置

**技术选型**：
- `cryptography`（Python 包，成熟）
- `argon2-cffi`（Argon2id）

**不做**：
- 不自己发明加密算法
- 不把主密码存任何地方
- 不在内存中保留超过必要时间

### 3.3 恢复

**流程**：
1. 用户选 `.wvbak` 文件
2. 提示输主密码
3. 解密（密码错 → 提示重试）
4. 备份当前数据（可选，提示用户）
5. 解压覆盖
6. 重启应用

**安全**：
- 恢复前弹确认"当前数据将被覆盖"
- 建议用户先备份当前数据

### 3.4 设置页

- "备份"按钮 → 上述流程
- "恢复"按钮 → 上述流程
- 上次备份时间（记在 `appearance.json` 或单独文件）

### 3.5 自动备份（可选）

如果 token 允许：
- 设置里可开"每周自动备份"
- 备份到用户指定目录
- 保留最近 4 个版本
- **如果太复杂，不做，留 M9**
