## 第一部分：修 bug + 密码管理器

### 1.1 设置界面拖拽关闭 bug

**现象**：设置界面全选密码框文字，鼠标拖到设置外 → 设置自动关闭。

**根因**：`点击外部关闭`逻辑误把拖拽当作"点击外部"。

**修**：拖拽不应触发关闭。

### 1.2 密码管理器条目 UI 细节

| 问题                  | 修法                                                         |
| --------------------- | ------------------------------------------------------------ |
| 显示/隐藏密码是"眼"字 | 换成 SVG 眼睛图标                                            |
| 编辑是"改"字          | 换成 SVG 铅笔图标                                            |
| 删除                  | 换成 SVG 垃圾桶图标（**红色**）                              |
| 账密字体与简介一样    | 账密加粗或加深，与简介区分                                   |
| 命名字体太普通        | 尝试更醒目、主流的字体；目标是清楚、识别度高。你判断具体字体 |

### 1.3 删除密码管理器时清理数据

**行为**：
- 删密码管理器导航项 → 弹确认"将删除所有 N 条密码，不可恢复"
- 确认 → 删 `vault_entries` + `vault_sections`
- **主密码保留**（全局设置，不属于密码管理器）

**重建密码管理器** → 用已有主密码解锁，不重设。

### 1.4 密码管理器备份

**行为**：
- 密码数据（`vault_entries` / `vault_sections`）**包含在备份里**
- 备份文件用备份密码加密
- 恢复后，密码数据回到备份时的状态
- **恢复后主密码保留当前的**（不覆盖，不跟着备份走）

### 1.5 锁定后不能点眼睛

**保持现状**。锁定 = 隐藏明文。复制密码仍可用。

## 第二部分：音乐悬浮球重做

### 2.1 三种状态

**状态 1：鼠标不在球上 + 音乐未播放**
- 球 + 音乐符号（静态）
- 周围无内容

**状态 2：鼠标不在球上 + 音乐播放中**
- 球内音乐符号**旋转**
- 球上方：音符从大变小，向上升起，尾部渐变消失
- 长度合理，不要过长
- 参考资料：网上常见的"音乐可视化"动画（自己搜索参考）

**状态 3：鼠标在球上**
- 半透明黑布遮住球
- 球上显示播放/暂停符号（颜色能看清即可）
- 周围按键通过动画展开
- 鼠标在一定范围内（建议 50px）按键不消失

### 2.2 悬停展开布局

**固定位置（必须）**：
- **最左**：上一首
- **最右**：下一首
- **最上**：音量键（音量符号）
  - 悬停 或 点击 → 音量胶囊
  - **竖放**，从音量键向上扩展
  - 长度：常规音量条长度（约 100-150px，你判断具体值）
  - 鼠标左键拖动 或 滚轮调节
  - 关闭：鼠标离开音量键+胶囊范围时自动关闭
  - 视觉：胶囊和音量键看起来是**一个整体**

**其他按键（自适应或固定）**：
- 打开面板
- 播放方式切换（符号直接显示当前方式：单曲循环 / 随机 / 顺序 / 列表）

**布局美观**：
- 可以对称或不对称
- 也可以只加"播放方式切换"凑齐
- 你判断具体排布

### 2.3 面板展开

**方向按位置**：
| 位置     | 展开方向             |
| -------- | -------------------- |
| 右下角   | 从球向左扩           |
| 正中间   | 从中间向两边扩       |
| 右侧中间 | 上下（暂定，你判断） |

**展开后的形态**：
- 整体是**长胶囊**，厚度比悬浮球小
- 胶囊中一头有一个比其厚度大的圆 = 悬浮球
- 球展开后**固定**，周围无其他内容
- 展开动画像分组覆盖式胶囊

**长度**：
- **不超过右侧工作区长度**，两边留空隙
- 美观至上，具体长度你判断

**面板内容**：
- 缩小键（返回悬浮球）
- 歌名
- 进度条 + 时间进度（主体）
- 切换歌单
- 切换播放方式
- 音量
- 上/下一首 + 播放/暂停：
  - **球在边角**：播放/暂停**代替球**位置，上/下一首放旁边
  - **球在中间**：上/下一首放两侧；进度条放胶囊**上方线条**，经过球时有个小突起

### 2.4 右键菜单（悬停时才有）

**从上到下**：
| 栏     | 内容                                            |
| ------ | ----------------------------------------------- |
| 第一栏 | 打开面板 / 关闭面板（切换）                     |
| 第二栏 | 歌名（固定长度，不够滚动）                      |
| 第三栏 | 上一首、播放/暂停、下一首（符号）               |
| 第四栏 | 音量符号 + 进度条                               |
| 第五栏 | 当前播放方式（鼠标悬停 → 二级菜单切换其他方式） |

### 2.5 歌名展示（未悬停时）

**你判断**，候选：
- A. 悬浮球下方横滚
- B. 围绕悬浮球一定角度（如 45°-135°）滚动
- C. 其他方案

**注意**：不要和向上弹出的音符冲突（B 方案会影响上方区域）。

### 2.6 动画要求

- **丝滑**：所有展开/收起/切换用动画
- **优先用图标代替文字**
- 弧线展开用 GSAP MotionPathPlugin（M9 已用）

### 2.7 容差与交互

- 悬停球上 → 展开按键
- 鼠标离开球 50px 范围才收回
- 拖着音量条时**不收回**
- 鼠标在音量胶囊上**不收回**

### 2.8 节拍粒子修复

**现象**：M9 实现的节拍粒子没出现。

**排查**：
- AnalyserNode 是否正确连接
- fftSize / 阈值是否合理
- 是否只在音乐播放时才启动

**调整**：播放音乐时明显可见，不刺眼。
