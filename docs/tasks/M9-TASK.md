## 阶段 1：密码管理器 + 备份重构 + 附件垃圾回收

### 1.1 密码管理器

#### 页面类型

注册 `password_vault` 为系统页（layer: core, multi_instance: false）：
- 通过"新建系统页"入口创建
- 归入系统分组
- 默认图标 🔒

#### 数据模型

**新表 `vault_sections`**（分区，可拖动排序）：
- id
- name
- sort_order
- created_at

**新表 `vault_entries`**：
- id
- section_id（外键）
- name（命名，用于搜索）
- url（可选）
- username（账号）
- password_encrypted（密码，加密存储）
- note（备注/简介）
- sort_order
- created_at
- updated_at

**密码字段加密**：
- 用 M8 阶段 5 的 Argon2id + AES-GCM 方案
- 复用 `backend/app/backup_file.py` 里的加密函数
- **主密码**：在"设置 → 隐私"里设置（和备份密码**可以是同一个**，也可以分开——你判断）
- 本会话内记住（内存，不落盘）
- 应用重启后要重输

**重要决策**：密码管理器主密码和备份密码是**同一个**还是**分开**？你判断，说明理由。
- 同一个：少记一个密码
- 分开：更安全（一个泄露不影响另一个）

#### 界面

**布局**：像专页的网站区块

- 顶部：分区 Tab + 搜索框 + "新建条目"按钮
- 每个分区是一张卡片，可拖动排序
- 分区内条目列表

**每条数据显示**：
```
[拖拽键] [命名(下划线，点击开网址)]  [账号]  [复制账号]  [密码(星星)]  [复制密码]  [编辑] [删除]
         [备注/简介]
```

- 命名：如果是网址，下划线 + 点击打开。如果没有网址，正常文字
- 账号：点击"复制账号"按钮
- 密码：默认显示 `••••••`，点击眼睛图标显示
- 复制键：复制到剪贴板，有 toast 提示
- 编辑、删除

**右键菜单**：
- 一键置顶（区块内置顶，拖到该分区最上面）
- 真置顶（该条目固定列表顶部）
- 锁定
- 编辑 / 删除 / 移动
- 显示 / 隐藏密码

**解锁逻辑**：
- 每次进入密码管理器输入一次主密码
- 本会话内切换显示/隐藏不用再输
- 切换页面后重新锁定

**不做**：
- 一键显示所有密码（易误操作）

#### 设置

- "设置 → 隐私"里设置主密码
- 主密码 ≥ 12 位
- 忘记密码无法恢复（提示用户）

### 1.2 备份重构

**核心改动**：**备份密码只需设置一次，备份时不输，恢复时输。**

#### 设置密码

**位置**：设置 → 隐私 → 备份密码

- 一次性设置（≥12 位）
- 可修改
- 忘记无法恢复（提示用户）
- 本会话内记住（内存），重启后要重输
- 用 Argon2id 派生密钥 + AES-GCM

#### 备份

- 位置：设置 → 备份/恢复
- 点"立即备份" → **不用输密码**（用已设密码自动加密）
- 可选命名（如"十月版本"）
- 存到 `backend/data/backups/`
- 文件名：`weaveverse-YYYY-MM-DD-HHMM-<命名>.wvbak`
- 成功后 toast："已备份到 <路径>"
- **如果没设密码**：提示"请先设置备份密码" + 跳转按钮
- 保留最近 5 个，超出的提示删除

#### 恢复

- 显示历史备份列表（按时间倒序）
- 每条显示：
  - 命名（或"（无命名）"）
  - 时间（本地时间格式 `2026-10-11 14:32`）
  - 大小
- 点"恢复" → **输密码** → 确认覆盖
- 恢复前自动把当前数据备份到 `backend/data/safety/`
- 恢复后提示"已恢复，请重启应用"

#### 时间格式修复

- 所有时间显示用 `2026-10-11 14:32` 格式
- 不是 ISO、不是 UTC、不是时间戳

#### 不再做的事

- 不再让用户"另存为"选位置（默认 `backend/data/backups/`）
- 不再每次备份输密码
- 不再有"永久记住密码"（仅会话内）

### 1.3 附件垃圾回收

#### 图库删除时两个选项

- **仅从图库移除**（文件保留，doc 还能用）
- **彻底删除**（如果 doc 没引用；如果 doc 引用着，提示"有 N 处引用，不能删"）

#### 设置里加"清理未使用附件"

- 扫描 `attachments/`，找出没有任何引用的文件
- 列出让用户确认
- 一键清理

#### 怎么判断"被引用"

- 扫数据库里所有区块内容（`blocks.content`）的 JSON
- 扫 doc 的 markdown 文本
- 扫 bookshelf 的 cover_path
- 扫 photo_library 的 filename
- 扫 icons / backgrounds 的引用
- 只要被任何一处引用，就不算垃圾

## 阶段 2：音乐悬浮球

### 2.1 位置

**可调**：
- 右下角（默认）
- 正下方
- 右侧中间

设置里切换。

### 2.2 默认状态（未悬停）

- 悬浮球显示：球内滚动歌名（marquee）
- 球上方：**音乐符号随节拍向上弹出**，到一定位置渐变消失
- 节拍符号用 Web Audio API AnalyserNode 获取音频能量

### 2.3 悬停状态

- 鼠标悬停 → **圆周弧线丝滑展开按钮**：
  - 左侧：上一首
  - 右侧：下一首
  - 上方：音量（悬停出音量条，调节时不消失）
  - 中心：播放/暂停
- **鼠标在小范围内移动时按钮不消失**（容差范围）

### 2.4 播放/暂停

- 点击播放/暂停 → 播放/暂停
- **右键菜单**：
  - 切换歌单（播客 / 我喜欢的 / 收藏 / 播放列表）
  - 打开面板
  - 播放控制
  - 音量

### 2.5 播放方式

- 单曲循环 / 顺序播放 / 随机播放
- 一个按钮循环切换

### 2.6 重启恢复

- 重启后自动从上次位置继续播放

### 2.7 面板动画

- 打开：从中心往外扩
- 关闭：往中间缩
- 右下角位置：往左扩 / 往右缩

### 2.8 依赖

**动画库**（你选，说明理由）：
- @vueuse/motion
- GSAP
- 原生 CSS transition

**优先用现成库，不要从 0 写弧线动画。**
