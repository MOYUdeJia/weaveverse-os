## 第一部分：修复遗留 Bug

### 1.1 修复设置页 UI 重复
- **现象**：系统状态面板（版本检测）挂在了设置页的每一个栏目最上方。
- **要求**：将系统状态面板单独抽出，只放在「设置 → 通用」的最下方，或者单独建一个「关于」Tab。不要影响其他 Tab。

### 1.2 彻底修复数据迁移逻辑（防误删）
- **现象**：旧目录里的跳过文件（whisper_models）被误删，且旧数据库没删掉。
- **要求**：
  - **只删已迁移的文件**：迁移成功后，遍历旧目录，只删除那些成功复制到新目录的文件/文件夹。被跳过的（如 `whisper_models`）留在原地。
  - **安全清理旧库**：旧数据库可能在运行中被锁定。在写入新指针文件后，将旧库重命名为 `weaveverse.old.db`（或者丢进回收站逻辑）。下次启动时，如果发现旧库，再尝试删除。确保用户绝对不会在旧目录看到原来的主库。

## 第二部分：桌面透明玻璃 UI（特殊设置）

### 2.1 原生窗口透明
- **设置**：在设置 → 外观中增加「透明玻璃模式」开关（默认关闭）。
- **实现**：修改 `main.py`，如果开关开启，`webview.create_window(..., transparent=True, frameless=True)`。
- **拖拽区**：由于开启无边框后窗口无法拖动，必须在主界面顶部（或侧边栏顶部）增加一个高度约 30px 的隐形拖拽条，设置 CSS `-webkit-app-region: drag`。

### 2.2 毛玻璃 CSS 重构
- 开启透明模式后，`body` 背景设为全透明。
- 主界面的所有面板（侧边栏、工作区、弹窗、卡片）背景设为 `rgba(255, 255, 255, 0.6)`（暗色主题下为 `rgba(0,0,0,0.6)`），并加上 `backdrop-filter: blur(20px)`。
- **设计感**：使用 `frontend-design` skill，确保玻璃边缘有细微的高光，层次分明。

## 第三部分：独立系统级番茄钟悬浮窗（Desktop Pet 模式）

**核心思路**：不要用网页里的悬浮球，用 pywebview 再开一个独立的系统级置顶小窗口。

### 3.1 悬浮窗创建
- **触发**：在主应用点击“开始专注”后，后端调用 `webview.create_window` 弹出一个无边框、置顶（`on_top=True`）、透明的微型窗口（大小约 150x150）。
- **UI**：里面只显示一个圆环倒计时和剩余分钟数。可以按住拖动。

### 3.2 边缘隐藏（QQ 模式）
- 监听鼠标事件：如果窗口被拖动到屏幕左/右/上边缘，自动把窗口一半移出屏幕外（只留 5px 露出来）。
- 鼠标移上去时，平滑滑出。

### 3.3 右键菜单与全屏模式
- 悬浮窗右键弹出菜单：暂停、放弃、进入全屏专注、隐藏。
- **全屏专注**：点击后，悬浮窗扩展为全屏（或另开一个全屏窗口），背景变暗，中间显示巨大的倒计时、励志语录，并播放 Web Audio 生成的白噪音。按 Esc 退出全屏，变回悬浮窗。
