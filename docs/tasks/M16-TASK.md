## 第一部分：修复番茄钟 Bug 并极速美化

1. **排查点开卡死**：检查小窗与主窗口的通信轮询频率，避免主线程阻塞或死循环。确保小窗的鼠标事件（拖拽、右键）不会引发无限重渲染。
2. **桌宠极致美化（132px）**：
   - 现在的红番茄太糙。请用 SVG 或高质量 CSS 画一个带光影、有圆润质感的“立体小番茄”。
   - 进度圈嵌在番茄内部边缘，平滑过渡。
3. **专注控制台（取代侧边栏列表）**：
   - 删掉侧边栏原本拥挤的列表。
   - 在侧边栏放置一个“专注控制台”按钮，点击弹出**模态框**（类似设置/AI面板）。
   - 弹窗内用卡片或清晰列表展示所有番茄钟（名称、时长、循环次数）。
   - **每一项右侧必须有一个明显的“▶ 启动”按钮**，点击直接开始专注并弹出番茄桌宠。

## 第二部分：实装插件系统（MVP 版）

1. **后端逻辑**：
   - 在 `data/plugins/` 目录下扫描插件。
   - 解析每个子文件夹的 `manifest.json`（包含 id、name、version、icon、entry）。
   - 提供 API 供前端读取插件列表。
2. **前端加载与沙箱隔离**：
   - 插件页面必须用 `<iframe>` 加载，绝对隔离，防止污染主系统。
   - 点击插件时，在右侧工作区渲染 iframe。
3. **插件管理面板**：
   - 右下角添加一个“插件”图标（与 AI 聊天图标并排）。
   - 点击弹出“插件管理”面板。
   - 支持导入 `.zip` 格式的插件（解压到 `plugins/`）。
   - 列表展示已安装插件，支持导出、删除。
   - **预留插件市场接口**：UI 上留一个空的 Tab 或按钮，显示“敬请期待”。
4. **开发者文档**：
   - 自动生成 `docs/PLUGIN-GUIDE.md`，写清插件目录结构、`manifest.json` 字段说明，以及如何用最简单的 HTML 写一个示例插件。
