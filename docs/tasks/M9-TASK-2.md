## 第一部分：密码管理器修

### 1.1 密码框组件修复

**Bug**：输入密码时右侧有小眼睛图标（显示/隐藏密码），鼠标点输入框外后眼睛消失，再聚焦输入框也不恢复。

**根因**：input 失焦时眼睛隐藏，重新聚焦时状态没重置。

**要求**：眼睛状态跟随输入框聚焦状态正确显示/隐藏。

### 1.2 主密码设置/修改流程重构

**首次设置主密码**（进入密码管理器时）：
- 新密码 + 确认密码
- 两次不一致 → 提示
- 长度 ≥ 12

**修改主密码**（设置 → 隐私）：
- 点"修改密码" → **内联展开表单**（不弹窗）：
  - 原密码 + [验证按钮]
  - 验证通过后展开：新密码 + 确认新密码
  - 提交 → 提示"修改成功"
- 新密码与原密码相同 → 提示"新密码不能与当前密码相同"
- 新密码与确认密码不一致 → 提示

**备份密码**：同样逻辑（首次设置 + 修改）。

### 1.3 条目 UI 重设计（单行布局 + 简介第二行）

**核心目标**：**单行展示主信息，一目了然；简介单独第二行，只在有内容时显示。**

**布局**：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ [📌][🔒] 命名...          账号 xxx...        密码 ••••••   [📋][📋]  [✏️][🗑️] │
│         简介文字，小字灰色，一行，超长省略号                                   │
└─────────────────────────────────────────────────────────────────────────────┘
```

**规格**：

| 部分         | 规格                                                         |
| ------------ | ------------------------------------------------------------ |
| 📌 / 🔒 图标   | 固定小尺寸，名字前                                           |
| **命名**     | **弹性最宽，最大字号，加亮，主视觉**；超长省略号             |
| 账号         | 固定宽度，超出省略号，**悬停显示完整**                       |
| 密码         | 固定宽度，默认 `••••••`，点眼睛显示                          |
| 复制账号按钮 | **大图标按钮（32×32 或 36×36）**，带背景色，hover 高亮       |
| 复制密码按钮 | 同上                                                         |
| 编辑 / 删除  | 固定位置，**悬停条目才显示**                                 |
| **简介**     | **第二行，小字灰色，一行，超长省略号**；无简介时不显示第二行 |

**行高**：
- 无简介：约 48px
- 有简介：约 64-72px

**关键**：
- 所有条目**列宽固定**，上下对齐
- 命名是主视觉
- 复制按钮**大而醒目**
- 悬停显示编辑/删除
- **用 CSS 变量适配主题**

**置顶/锁定符号**：名字前（方案 A）。

**如果空间不够**：
- 优先保证命名、账号、复制按钮
- 密码列可以更窄
- 编辑/删除可以塞进右键或悬停菜单

### 1.4 右键菜单优化

**命名改动**：

| 原名     | 改为         |
| -------- | ------------ |
| 一键置顶 | **移到最前** |
| 真置顶   | **置顶**     |

**符号标识**（不放进右键菜单，直接显示在条目上）：
- **置顶**：📌 或 pin 符号，显示在**左上角**或名字前
- **锁定**：🔒 符号，显示在**左上角**或名字前
- **不影响其他按钮排版**

**如果已置顶/已锁定**：符号显示
**如果未置顶/未锁定**：符号不显示

### 1.5 锁定后不能复制密码 bug

**现象**：锁定状态下点"复制密码"无反应。

**要求**：锁定只影响"**显示密码**"（眼睛点击），不影响"**复制密码**"。

**理由**：用户按锁定可能只是不想让屏幕显示明文，但操作（复制）仍应可用。

**如果你认为锁定应该禁止复制**：给出理由，我们讨论。

### 1.6 首次设置密码也加确认

**首次设置主密码时**：新密码 + 确认密码（两次）。

**首次设置备份密码时**：同上。

## 第二部分：音乐悬浮球

### 2.1 位置

**可调**（设置里切换）：
- 右下角（默认）
- 正下方
- 右侧中间

### 2.2 默认状态（未悬停）

- **悬浮球**：显示球内滚动歌名（marquee 循环）
- **节拍粒子**：球上方有音乐符号随节拍向上弹出，到一定位置渐变消失
- **节拍数据**：Web Audio API `AnalyserNode` 获取音频能量

### 2.3 悬停状态

- 鼠标悬停 → **圆周弧线丝滑展开按钮**（用 GSAP 做）：
  - 左侧：上一首
  - 右侧：下一首
  - 上方：音量（悬停出音量条，调节时不消失）
  - 中心：播放/暂停
- **鼠标在小范围内移动时按钮不消失**（容差范围，如 50px）

### 2.4 播放控制

- 点击中心：播放/暂停
- **右键菜单**：
  - 切换歌单（播客 / 我喜欢的 / 收藏 / 播放列表）
  - 打开面板
  - 播放控制（上一首 / 下一首 / 暂停 / 播放）
  - 音量

### 2.5 播放方式

- 单曲循环 / 顺序播放 / 随机播放
- 一个按钮循环切换

### 2.6 重启恢复

- 重启后自动从上次位置继续播放

### 2.7 面板动画

- 打开：从中心往外扩
- 关闭：往中间缩
- 右下角位置：往左扩 / 往右缩

### 2.8 依赖

**动画库**：GSAP（已定）。
