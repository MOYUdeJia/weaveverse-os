## 第一部分：密码系统重构

### 1.1 核心改动

**统一密码**：废弃"主密码"和"备份密码"两个概念，改成**一个"安全密码"**。

**作用**：
- 打开密码库
- 加密备份
- 一次设置，全局通用

**会话逻辑**：
- 应用启动后，第一次访问密码库 / 备份时输一次
- 本会话内所有密码相关操作**都不用再输**
- 应用关闭后重新锁定
- **密码库进入仍需输一次安全密码**（与备份独立解锁，但用同一个密码）

**密码长度**：
- 最低 **8 位**
- 建议 12 位（提示）

### 1.2 修改隐私设置页

**位置**：设置 → 隐私

**内容**：
- **安全密码**：`已设置` / `未设置`
- **修改安全密码**按钮 → 内联展开：
  - 原密码 + [验证]
  - 验证通过 → 新密码 + 确认新密码
  - 提交 → "修改成功"
  - 新密码 = 原密码 → 提示"不能与当前相同"
- 备份页相关设置

### 1.3 修改备份页

**位置**：设置 → 备份/恢复

**页面顶部提示**：
> 使用备份/恢复需要输入安全密码，本次登陆有效

**行为**：
- 未设安全密码 → 提示"请先设置安全密码"+ 跳转按钮
- 已设但本会话未解锁 → 提示输入安全密码
- 已解锁 → 显示备份/历史列表

**备份**：
- 点"立即备份" → **不用输密码**（本会话已解锁）
- 可选命名
- 存到 `backend/data/backups/`
- 默认**加密**（`.wvbak`）
- 保留最近 5 个

**恢复**：
- 显示历史列表（时间倒序）
- 时间格式：`2026-10-11 14:32`
- 点"恢复" → 确认覆盖
- **恢复前自动存**：`backend/data/safety/YYYY-MM-DD-HHMM/`
- 保留最近 3 个 safety
- 恢复后提示"已恢复，请重启"

### 1.4 改密码逻辑（事务化）

**流程**：
```
1. 验证旧密码
2. 派生 old_key（Argon2id）
3. 用 old_key 解密所有条目 → 明文列表
4. 派生 new_key
5. 用 new_key 重新加密所有条目
6. 事务提交（全成功或全回滚）
7. 更新 privacy.json 的哈希+盐
```

**关键**：步骤 3-5 是事务，**任何一步失败全部回滚**。

**验证**：改密码后条目仍能用新密码解。

### 1.5 备份的核心逻辑（关键）

**备份时**：
1. 读数据库
2. **密码库条目：用安全密码解密 → 明文**
3. 打包（整体，包含明文条目）
4. 用安全密码加密整个包 → `.wvbak`
5. 存储

**恢复时**：
1. 用安全密码解密 `.wvbak`
2. **密码库条目：用当前安全密码重新加密**
3. 写入数据库
4. 主密码不跟备份走

**结果**：
- 改密码不影响旧备份的可恢复性
- 恢复任何备份都能读

### 1.6 删除密码库导航项

- 删 `vault_entries` + `vault_sections`
- 弹确认"将删除所有 N 条密码，不可恢复"
- **安全密码保留**（管备份）
- 重建密码库 → 用原密码解锁，条目为空

### 1.7 清理测试数据

**用户当前测试数据已崩**：
- 删所有 `vault_entries`
- 删所有 `vault_sections`
- 保留 `privacy.json` 里的哈希+盐（用户已设安全密码）
- 或：全部清空，让用户重设

**你判断**。清理脚本在迁移里执行一次即可。

### 1.8 修 bug：body stream already read

**现象**：进入密码库后，顶部提示 `Failed to execute 'text' on 'Response': body stream already read`。

**根因**：前端错误处理读 Response body 两次。

**修法**：错误处理里只读一次。

### 1.9 修 bug：改密码提示"现有条目解不开"

**根因**：1.4 修复后自然解决。

## 第二部分：悬浮球重做

### 2.1 架构：通用组件

**不按位置做三个版本**。做**一个通用组件**：
- 位置：预设（右下 / 正下 / 右侧中）+ 自由拖动
- 悬浮球展开方向：**根据周围空间自动判断**
- 面板展开方向：设置里选"从中间向两边" 或 "从一侧"

**位置选择入口**：设置 → 外观 → 悬浮球位置

### 2.2 拖动模式

**不是直接拖球**。

**流程**：
1. 设置里点"移动悬浮球"
2. 进入移动模式（球出现拖拽提示，其他 UI 变暗）
3. 拖动球到目标位置
4. 右上角或某个位置点"完成"确认
5. 位置保存

**或者**：放进右键菜单，右键 → "移动悬浮球"

**你判断哪个更好。**

### 2.3 悬浮球三种状态（同 M9.1）

**状态 1：未播放 + 鼠标不在球上**
- 球 + 静止音乐符号
- 周围无内容

**状态 2：播放中 + 鼠标不在球上**
- 球内符号**旋转**
- 球上方：音符升起（**修 bug：数量太少、只有一行、太短**）
- 增加：多行、更多、更长
- 歌名在球下方横向滚动（**修 bug：速度太快 → 改慢**）

**状态 3：鼠标在球上**
- 半透明黑布 + 播放/暂停符号
- 周围按键展开

### 2.4 通用 bug 修复

| Bug                                                        | 修法                                                         |
| ---------------------------------------------------------- | ------------------------------------------------------------ |
| **悬浮球展开时位置会动**                                   | 球本身固定不动，只有周围元素展开/收起                        |
| **展开内容超出边框**                                       | 根据位置动态判断展开方向，向右下角则内容集中在第二象限（左上方向） |
| **右键菜单跑到屏幕外**                                     | 计算菜单尺寸，超出边界则朝反方向弹出                         |
| **音量键调不了**                                           | 重做成"苹果下拉"式一体音量槽                                 |
| **音符太少**                                               | 增加数量和长度                                               |
| **歌名滚动太快**                                           | 改慢                                                         |
| **展开后滚轮调音量关不掉**                                 | 修：滚轮调节不触发关闭                                       |
| **直接展开悬浮球放到音量上用滚轮调了一下然后展开关不掉了** | 修：容差范围内滚轮操作不触发关闭                             |

### 2.5 悬停展开布局

**固定位置（必须）**：
- **最左**：上一首
- **最右**：下一首
- **最上**：音量键（音量符号）
  - 悬停 或 点击 → 音量胶囊
  - **竖放**，从音量键向上扩展
  - **一体式**：胶囊和音量键视觉相连
  - 苹果手机下拉菜单风格
  - 长度：120-150px
  - 调节：拖动 + 滚轮
  - 关闭：鼠标离开"音量键 + 胶囊"范围自动关闭
  - 按着时不关

**其他按键**：
- 打开面板
- 播放方式切换

### 2.6 面板设计

**核心视觉：悬浮球与胶囊是一体的。**

**球在端点（形态 A）**：
```
                                        ● ← 球
┌──────────────────────────────────────┐
│ ═══════════════════════════════════│ ← 上下边框进度条
│ ⏮ ⏯ ⏭  歌名 · 时间 · 音量 · 歌单 · 播放方式 │
└──────────────────────────────────────┘
```

- 球在胶囊的端点
- **球的圆和胶囊的圆角无缝连接**，看起来像"胶囊一端长了个球"
- 不是球覆盖在胶囊上，也不是球旁边接一个胶囊
- 视觉上是一个整体

**球在中间（形态 B）**：
```
                      ● ← 球
        ┌─────────────┴─────────────┐
        │ ═══════════════════════ │ ← 上下边框进度条（经过球时不断开）
        │ ⏮ ⏯ ⏭ 歌名 · 时间 · 音量 · 歌单 · 播放方式 │
        └───────────────────────────┘
```

**两种设计（你选一个，说明理由）**：

- **A. 无缝连接**：胶囊穿过球的位置，球叠在胶囊上，视觉上一体
- **B. 断开但吻合**：胶囊在球位置断开，断开处的曲线**正好是球的圆形轮廓**

**关键**：
- 无论哪种，视觉上都不能"球浮在胶囊上面"或"球旁边有个胶囊"
- 断开处（如果断开）必须**沿球的圆弧切**
- 颜色一致，看起来是一个整体

**进度条**：在胶囊的上下边框上，**经过球时不断开**（球和进度条也是融为一体的）。

**你的实现方向**：优先 A（无缝），如果 CSS 难度大再考虑 B。

### 2.7 进度条设计（关键）

**放在胶囊的上下边框上**（两根线同步动，形成"边框进度条"）。

- **可自定义颜色**（甚至可以彩色）
- 经过悬浮球时**不断开**（球在中间时）
- 从 0% 到 100%，进度条沿边框填充

**这是本任务书的创新点**，你判断实现方式。

**设置**：
- 进度条颜色：单色 / 彩色渐变

**进度条经过球时**：
- 球相当于进度条上的一个凸起或节点
- 进度条不断开，视觉上穿过球
- 参考：像一根线串着一颗珠子

### 2.8 面板展开长度

| 位置   | 长度                                         |
| ------ | -------------------------------------------- |
| 右下角 | 从球向左扩，最长 480px，不超 `100vw - 340px` |
| 正下方 | 总宽度 60-70% 屏幕宽                         |
| 右侧中 | 暂不做，或从通用里选                         |

**两侧留空隙**，美观至上。

### 2.9 右键菜单（悬停时）

**五栏**：
| 栏   | 内容                        |
| ---- | --------------------------- |
| 1    | 打开 / 关闭面板             |
| 2    | 歌名（滚动）                |
| 3    | ⏮ ⏯ ⏭                       |
| 4    | 音量符号 + 进度条           |
| 5    | 播放方式（悬停 → 二级菜单） |

**修复**：菜单不再超出屏幕，右下角向上弹出。

**可选**：加"移动悬浮球"项。

### 2.10 歌名展示

**球下方横向滚动**（保持 M9.1 方案）。
- 速度改慢
- 悬停 / 展开时收起

### 2.11 节拍粒子

**增加**：
- 数量（多行）
- 长度（更长）
- 频率

**不刺眼**。播放时明显可见。
