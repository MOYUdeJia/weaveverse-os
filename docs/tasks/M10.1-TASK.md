## 第一部分：修 M10 遗留

### 1.1 背景不透明度 100% 不真

**修**：100% = 完全不透明。

### 1.2 欢迎封面尺寸

**要求**：**横向铺满，上到顶，下方留一点空间放标语**。

- 图片/视频 `object-fit: cover`
- 顶部对齐，底部留 10-15% 空间
- 标语（如"Weaveverse OS"或用户自定义文字）显示在底部留白区

### 1.3 主题导出位置

**导出**：弹"另存为"对话框，默认 `data/themes/`。

**导入**：文件选择器过滤 `.wvtheme` / `.json` / `.wvpack`。

## 第二部分：打包为安装程序

### 2.1 用 Inno Setup 生成安装包

**目标**：生成 `WeaveverseOS-Setup.exe` 安装程序。

**流程**：
1. 先跑 `build.ps1` 生成 `dist/WeaveverseOS/`
2. 用 Inno Setup 脚本打包该目录
3. 生成单个 `WeaveverseOS-Setup.exe`

**安装程序要求**：
- 用户可选择安装目录（默认 `C:\Program Files\WeaveverseOS\`）
- 创建开始菜单快捷方式
- 创建桌面快捷方式（可选）
- 支持卸载
- 卸载时**保留用户数据**（`%APPDATA%\WeaveverseOS\`）

**交付**：
- `installer.iss`（Inno Setup 脚本）
- `build-installer.ps1`（一键生成安装包）
- 使用说明写进 `docs/BUILD.md`

**如果 Inno Setup 不在本机**：
- 提供脚本 + 文档，让用户自己安装 Inno Setup 后运行
- 或者用 NSIS（如果你判断更合适）

### 2.2 绿色版保留

**保留现有 `build.ps1`**（生成绿色版），两者都提供。

## 第三部分：完整主题包系统（`.wvpack`）

### 3.1 格式定义

**`.wvpack` = zip 文件**，内部结构：

```
mytheme.wvpack
├── manifest.json
├── colors.json
├── splash/
│   ├── video.mp4          ← 开屏动画（可选）
│   └── image.png          ← 或图片
├── background/
│   ├── image.jpg          ← 背景图（可选）
│   └── video.mp4          ← 或背景视频
├── decorations/           ← 装饰元素（可选）
│   ├── logo.svg
│   └── corner.webp
├── sounds/                ← 音效（可选）
│   └── startup.mp3
└── preview.png            ← 预览图（用于列表显示）
```

### 3.2 `manifest.json`

```json
{
  "id": "dragon-girl",
  "name": "龙娘主题",
  "author": "xxx",
  "version": "1.0",
  "description": "龙娘元素 + 深海配色",
  "preview": "preview.png",
  "colors": "colors.json",
  "splash": {
    "type": "video",
    "path": "splash/video.mp4",
    "duration": 3
  },
  "background": {
    "type": "video",
    "path": "background/video.mp4",
    "opacity": 0.85
  },
  "decorations": ["decorations/logo.svg"],
  "sounds": {
    "startup": "sounds/startup.mp3"
  }
}
```

### 3.3 安装/切换主题包

**设置 → 主题**：
- 已安装主题包列表（含预览图）
- "导入主题包"按钮 → 选 `.wvpack` → 解压到 `data/themes/<id>/`
- 点击主题包 → 切换
- 右键 → 删除

**切换主题包时**：
- 颜色跟着变
- 开屏动画换成主题包的
- 背景换成主题包的
- 装饰元素渲染
- 音效播放（如果配置）

### 3.4 兼容 `.wvtheme`

**旧格式 `.wvtheme` 仍兼容**（只换颜色）。

### 3.5 使用 design skill

**如果你有 `frontend-design` 和 `taste-skill`**：
- 在设计主题列表 UI 时调用
- 让主题列表界面更精致

**如果没有**：按现有风格。

## 第四部分：制作龙娘主题包

### 4.1 素材来源

**参考仓库**：
- `https://github.com/yushua0808-cpu/dragon-codex-boot`（Windows 启动动画）
- `https://github.com/LeeRolling/dsh-chat-wallpaper`（动态壁纸）

**Agent 执行**：
1. clone 这两个仓库（用 git 命令）
2. 查看 README / 目录结构
3. 提取可用的视频/图片素材
4. 评估哪些适合做主题包素材

**如果 clone 失败**：告诉用户手动下载，放到指定目录。

### 4.2 制作主题包

**基于提取的素材，制作一个示例 `.wvpack`**：
- `manifest.json`：id `dragon-girl`，名称"龙娘主题"
- 颜色：参考素材配色
- 开屏动画：从 `dragon-codex-boot` 提取的视频（如果适合）
- 背景：从 `dsh-chat-wallpaper` 提取
- 预览图：截取一帧

**输出**：`backend/data/themes/dragon-girl.wvpack`

### 4.3 版权提醒

**在 `manifest.json` 的 `description` 里注明**：
> 素材来源：dragon-codex-boot / dsh-chat-wallpaper。仅供个人使用。
