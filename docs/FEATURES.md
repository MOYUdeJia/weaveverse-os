## 一、页面系统

### 页面类型（三层）

**第一层：通用型（multi_instance = true）**
- 可创建多个，右侧走区块系统，可自由添加/删除区块
- 提供模板（空白 / 健身 / 学习 / ...）
- 现有：markdown / todo / gallery / collection

**第二层：特殊型（fixed_layout = true）**
- 可创建多个，右侧固定布局，**不能添加区块**
- 类型：
  - `doc`：文档型。右侧单块 Markdown 编辑器，上下滚动
  - `plain`：纯文本型。左侧显示行号，可改行色，支持自动编号/点分条
  - `bookmarks`：网址型。右侧只有"添加网站"，紧凑排版
- **注意**：这一层是新概念，M5 做类型分层，M6 做具体类型

**第三层：单实例型（multi_instance = false）**
- 全局只能创建一次。再创建返回 409 + 前端提示"已存在"
- 现有：bookshelf
- 待加：music_collection（音乐收藏）、movie_collection（电影收藏）
- 待加：idea_box（IDEA 栏）、vault、future_plan、habit_tracker

### 三层命名

| 层   | 中文名 | 英文 key | 特征                |
| ---- | ------ | -------- | ------------------- |
| 一   | 通用页 | flex     | 自由组合区块        |
| 二   | 专用页 | focus    | 固定布局 + 特殊添加 |
| 三   | 系统页 | core     | 全局唯一            |

### 特殊添加

专用页没有通用"添加区块"按钮，但每个类型可以声明自己的"特殊添加"组件。

- bookmarks → "添加网站"
- 未来类型 → 各自的添加动作

前端注册表：`frontend/src/specialAdds/registry.js`

### 创建菜单（M7 阶段 2 重构）
- "+"菜单三入口：新建积木页 / 新建专用页 / 新建系统页
- **积木页**：合并原"空白页"和"从模板创建"
  - 弹窗上方"空白页"按钮
  - 弹窗下方模板卡片列表
- **专用页**：选类型（doc / plain / bookmarks / canvas）
- **系统页**：显示所有系统页类型（书架、图片库等）
  - 已创建的置灰，悬停提示"已创建，只能有一个"
  - 未创建的可点击

### 标签系统（双层设计）

| 层级           | 打在哪            | 作用域 | 谁能搜到          | 点击行为               |
| -------------- | ----------------- | ------ | ----------------- | ---------------------- |
| **专页级标签** | 专页设置里        | 跨页   | 全局搜索"专页"Tab | 跳全局搜索并过滤       |
| **页内标签**   | 网址/笔记的条目后 | 当前页 | 当前页内部搜索    | 跳当前页内部搜索并过滤 |

**视觉**：`#标签名 ` （后跟空格才完整），蓝色发亮，与普通文字明显区分。

**格式**：`#游戏 #我的世界` 这样多个标签，各带空格分隔。

**作用域互不干扰**：
- 专页级标签只在全局"专页"Tab 搜到
- 页内标签只在该页内部搜索里找到
- 一个专页可以同时有专页级标签和页内标签，两者独立

### 各类型页面搜索范围

| 类型   | 全局搜索（"全部"Tab） | 该类型 Tab        | 内部搜索                 |
| ------ | --------------------- | ----------------- | ------------------------ |
| 积木页 | 只搜名字              | 只搜名字          | 无                       |
| 专页   | 只搜名字              | 名字 + 专页级标签 | 页内标签                 |
| 系统页 | 只搜名字              | 只搜名字          | 各自定制（如书籍搜书名） |

## 三、分组系统（Telegram 风格，M5 核心）

### 界面结构
```
[竖版分组栏] [导航项栏] [工作区]
   48px宽     240px宽     剩余
```

- 竖版分组栏：默认只显示分组图标，hover 时向右展开显示名字
- 设置里可勾选"默认显示名字"（展开模式）
- 选择分组 → 中间栏显示该分组下所有导航项
- 分组栏支持：新建、编辑、删除、拖拽排序

### 分组规则
- 每个分组至少一个导航项，为空时自动删除
- 删除分组里最后一个导航项 → 提示"该分组将被删除"
- 分组数量：软提示（超过 8 个提醒）
- 新分组创建方式（方案 3）：
  - 新建分组时自动创建一个"分组导览页"（默认模板：md 区块 + 显示分组简介）
  - 用户可删掉它，删掉后分组空则自动消失
  - **替代方案**（被否）：必须从现有分组选一个导航项移入

### 分组信息页
- 点击分组名字（或不选中任何导航项时）→ 右侧显示分组信息
- 内容：
  - 分组名（可编辑）
  - 分组简介（可编辑）
  - 该分组下所有导航项列表（点击直接跳转）
  - 快捷操作：重命名、删除分组、修改图标

### 导航项操作
- 置顶 / 编辑 / 删除 / 移动到其他分组
- 集成方式：右键菜单 + 悬停操作图标
- 支持拖动排序

### 删除确认
- 删除导航项：弹确认
- 删除分组：弹确认（含"该分组有 N 个导航项"提示）
- 导航项重名检测：同分组内不允许重名，跨分组允许

### 分组细节
- **图标**：emoji + 上传（复用 M4.1 图标选择器）
- **hover 动画**：48px 收起 → 200px 展开，300ms
- **窄窗口**：< 900px 强制收起，鼠标放上去临时展开
- **数据迁移**：所有现有 nav_items 迁入"默认分组"
- **单实例归属**：所有单实例类型归入"系统"分组（不可删改）
- **跨分组移动**：右键菜单"移动到..." → 选分组
- **导览页类型**：新增 `group_overview` 特殊 page_type
- **重名检测**：同分组内不允许同名（大小写不敏感，去空格比较），跨分组允许
- **删除确认**：删导航项弹确认；删分组弹确认（含导航项数量）
- **软约束**：不限制分组数量

### 分组置顶规则
- 系统分组始终置顶，固定第一位
- 其他分组不提供置顶功能

### 分组栏样式（未来设置项）

| 样式           | 位置 | 展开方式                                                   |
| -------------- | ---- | ---------------------------------------------------------- |
| 推栏式（当前） | 左侧 | hover 时整个分组栏展开，把导航栏往右推                     |
| 覆盖式·单图标  | 左侧 | 只有悬停的分组图标自己向右扩展，其他分组不动，导航栏不挤压 |
| 覆盖式·底部    | 底部 | 鼠标悬停在图标上时，名字向上弹出                           |
| 默认展开       | 左侧 | 分组栏默认就是展开状态，不再收起                           |

**排期**：M7 主题 + 设置系统时一起做。

### 已知 UI bug（未来修）

  可选解法：

  - B. 分组栏改"点击固定展开"

  建议 A 或 C。

## 十、设计原则

1. **本地优先**：数据永远在本地
2. **页面类型三层**：通用 / 特殊 / 单实例
3. **加新类型不改核心代码**
4. **数据与配置分离**
5. **前后端解耦**
6. **资源可替换**（开屏、图标、主题）
7. **开放格式**：可导出 Markdown / JSON
8. **不锁定**：可迁移
