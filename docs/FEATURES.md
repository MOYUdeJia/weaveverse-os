- `Ctrl+K` 全局搜索

### M9：密码管理器 + 音乐悬浮球 + 背景历史

#### 附件垃圾回收
（内容不变）

#### 密码管理器
- 分区（可拖动），内部搜索
- 每条字段：命名 / 网址 / 账号 / 密码 / 备注

- 右键：切换歌单、打开面板、播放控制
- 面板动画：从中心外扩 / 关闭回缩
- 重启从上次位置继续

- 可清除全部或单个

## 五、设计原则

1. **本地优先**
2. **页面类型三层**：积木 / 专用 / 系统
3. **加新类型不改核心代码**
4. **数据与配置分离**
5. **前后端解耦**
6. **资源可替换**
7. **开放格式**：可导出 Markdown / JSON
8. **不锁定**：可迁移
9. **多考虑丝滑动画**
10. **数据区块可拖动**
11. **优先用现成库**
