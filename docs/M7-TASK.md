## 2. 阶段 1：修 bug + 小优化

### 2.1 doc 右键菜单分隔线

现在"左对齐"和"居中"之间有一条分隔线，位置不对。应该把分隔线放在 **25% 和 左对齐 之间**，或者直接删掉分隔线。你判断哪个更清爽。

### 2.2 链接打开方式改回

- **普通左键点击** → 定位光标（可编辑链接文字）
- **Ctrl + 左键点击** → 系统浏览器打开
- **鼠标悬停链接** → 显示提示"Ctrl+点击打开链接"（tooltip 或 cursor 变化）

### 2.3 全局搜索改造

**搜索范围**（改）：
- 导航项标题 + 图标
- 分组名
- 书籍标题 + 作者
- **不搜正文、区块内容**

**结果显示**（改）：
- 每条结果**带路径**，如 `系统 > M2文档`
- 结果前有类型图标（积木页/专页/系统页）

**筛选 Tab**（新）：
- 全部 / 积木页 / 专页 / 系统页
- 点击 Tab 只显示对应层的结果

**修 bug**：
- 点搜索结果没反应 → 修好，能跳转到对应页面

### 2.4 笔记加时间戳

- 便携笔记保存时，记录时间
- 显示格式：`2026-10-09 14:32`
- 存哪里你定（笔记内容里嵌入？还是额外字段？）—— 建议放内容里（纯文本更易迁移）

### 2.5 页内 #标签 筛选

- **bookmarks 页**：顶部加一个输入框，输入 `#学习` → 只显示含此标签的网站
- **笔记页**：同理，输入 `#标签` → 只显示含此标签的行

不做全局标签系统。只做页内筛选。

### 2.6 导航项拖拽改造

**当前问题**：鼠标放在导航项上有时出现抓手，导致点击无效。

**两个候选方案**（你选一个，说明理由）：
- **A. 抓手图标**：hover 时右侧出现独立拖拽图标，只有拖它才排序，其他地方点击
- **B. 按住延迟**：鼠标按下 200ms 不动才进入拖拽，短按是点击

### 2.7 修分组右键菜单 bug

现象：分组右键菜单打开时，分组栏 hover 收回，菜单留在原地。

**可选解法**：
- A. 右键菜单打开时分组栏保持展开
- B. 分组栏改"点击固定展开"
- C. 右键菜单点击后短暂固定

你判断哪个最好，说明理由。

## 3. 阶段 2：主题系统 + 首次说明

### 3.1 淡色主题

- 预设 3-5 套淡色主题（如：暖白、薄荷、天蓝、樱粉、灰调）
- 设置页可选
- 主题切换即时生效，不用重启
- 用 CSS 变量实现

### 3.2 背景图上传

- **全局背景**：设置里上传一张图作为整个应用背景
- **分组背景**：每个分组可单独设置背景图（可选，不设置时用全局）
- 存储：`backend/data/backgrounds/`，`.gitignore` 排除
- 尺寸：建议限制宽度（如 2560px），超大图自动压缩

### 3.3 wallpaper 视频背景

- 支持上传 MP4 作为背景
- 存储：`backend/data/backgrounds/`
- 限制：文件大小上限（你定，建议 50MB）、时长上限（建议 30 秒循环）
- 性能：视频背景会占用 GPU，加一个"低性能模式"开关（禁用视频背景）

### 3.4 分组栏样式设置

设置里加一项，可选：
- 推栏式（当前）
- 覆盖式·单图标
- 覆盖式·底部（分组栏可放底部）
- 默认展开

**如果工作量太大**：先做"推栏 / 覆盖"两种，其他放 M8。

### 3.5 首次使用说明

- 首次启动时（或设置里手动打开）显示一个说明文档
- 内容：讲清楚积木页 / 专页 / 系统页三种类型、怎么建分组、快捷键一览
- 形式：可关闭的浮层 或 一个预置的 doc 页面

## 4. 阶段 3：音乐播放器 + 图片库

### 4.1 音乐播放器

**核心要求：不要自己从零写。** 去 GitHub / npm 找现成的：

**候选方向**（你搜，选一个，说明理由）：
- `vue-audio-player` / `vue3-audio-player`
- `plyr`（成熟、支持音频 + 视频）
- `howler.js`（底层，UI 自搭）
- `aplayer` + Vue 包装（Aplayer 是国内常见的简约播放器）

**功能**：
- 播放 / 暂停 / 上一首 / 下一首
- 进度条
- 音量
- 歌名 + 专辑图（如果有）
- 位置：可放上侧 / 下侧 / 右下角（设置里切）
- 音源：本地文件夹扫描 或 手动添加（你判断）
- 播放列表管理

**不做**：桌宠、打碟、歌词（放 M8+）

### 4.2 图片库

**核心思路：不重复存文件，加元数据层。**

**数据表**（新建，需要迁移）：
- `albums` 表：id、name、cover_filename、sort_order、created_at
- `photo_meta` 表：filename（关联现有附件）、album_id、note、added_at

**M7 只做单相册**（默认相册），多相册 M8。

**入口**：
1. 图片库页面 → "上传"按钮 → 上传图片 → 自动进默认相册
2. doc 里点图片 → 右键"加入图片库"→ 进默认相册
3. **重要**：从 doc 拖入的图**默认不进库**，用户主动加才加

**功能**：
- 网格 / 列表展示
- 点击 → 大图预览
- 预览里有"保存到本地"（原图，弹出保存对话框）
- 删除（从库里移除，但**不删附件本身**，因为 doc 可能还在引用）
- 图片库作为专用页类型（`photo_library`），单实例

**页面类型**：
- 在 `page_types.py` 注册 `photo_library`（layer: core, multi_instance: false）
- 默认不出现在"新建空白页"菜单（用户主动从设置或"+"里的单实例入口创建）
