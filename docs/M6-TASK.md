## 2. 范围

### 2.1 专用页四种类型

在 `page_types.py` 给下列类型加 `layer: "focus"`：

**doc（Markdown 长文排版）**
- 右侧一整块 Markdown 编辑器
- **核心诉求：文字排版美观**（行距、字号、段落间距舒服）
- 编辑 + 预览（分栏或切换，你选）
- 上下滑动
- 默认图标：📄

**plain（笔记型）**
- 顶部模式切换：**行号模式 / · 分条模式**
  - 行号模式：左侧显示行号
  - · 分条模式：每行自动加 `·` 前缀
- 可改行颜色（用户可选几种颜色，或自定义）
- 上下滑动
- 默认图标：📝

**bookmarks（网址集）**
- 紧凑排版
- 每条：标题（自己取）+ URL + `#标签`
- 点击标题打开网址
- **支持创建分区**（一个 bookmarks 页里可以分多个区，每区有自己的名字，网站归到区里）
- 走 `specialAdds/registry.js`
- 默认图标：🔖

**canvas（白板）**
- 无限画布
- 画笔 / 矩形 / 圆 / 箭头 / 直线 / 文本框
- 底部工具栏（画笔、图形、颜色、撤销、重做）
- 多个 canvas 实例独立
- 内容自动保存（JSON 塞 Block.content）
- 默认图标：🎨

**共同约束**：
- 不出现在"新建空白页"菜单
- 走独立入口："+"菜单加"新建专用页"
- 右侧无"添加区块"按钮
- 内容区占满、上下滑动
- **创建时如果不填图标，用默认图标**（用户懒得选时省事）

**数据结构**（推荐方案，你判断）：
- 专用页创建时自动创建一个固定类型的 Block（用户不能删）
- doc → `markdown`
- plain → `plain_text`（新建）
- bookmarks → `bookmarks`（新建）
- canvas → `canvas`（新建）
- 复用 blocks 表，不新增表

### 2.2 区块紧凑化 + code 区块

- 减小区块内边距和间距
- 区块可折叠（点标题栏），折叠状态记住
- **code 区块**：等宽字体 + 语言下拉，语法高亮可选（不引库）

### 2.3 锁定功能

**分组和导航项都支持锁定**：
- 锁定的项不能删除，可以编辑
- 后端：DELETE 时检查锁定状态 → 409
- 前端：右键菜单里删除项置灰
- 侧边栏/分组栏显示锁图标

**锁定的触发**：
- 右键菜单里有"锁定 / 解锁"项

### 2.4 导航项 UI 精简

现在导航项悬停显示"编辑 + 删除"两个按钮。

**改为**：
- 去掉"编辑 + 删除"按钮（都集成到右键菜单）
- 右侧位置放两个新图标：**锁标志**（锁定状态时显示）+ **置顶标志**（置顶状态时显示）
- 未锁定时不显示锁图标，未置顶时不显示置顶图标

### 2.5 不要做

- 不做全局搜索、便携笔记（M6.1）
- 不做 music_collection / movie_collection（M6.2）
- 不做 IDEA 栏
- 不引入 UI 组件库、TypeScript
- 不改 M5 分组系统核心逻辑、书架、阅读器
