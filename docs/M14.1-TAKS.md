## 第一部分：引入系统版本检测（必须最先做）

**背景**：用户反映更新了代码，但打开界面感觉和上个版本一模一样，怀疑是旧进程或旧构建包在运行。

**要求**：
- 在「设置 → 通用」或新建一个「关于」页面，加入系统状态面板。
- 显示以下信息：
  1. **前端构建时间**：在 Vite 构建时注入当前时间戳。
  2. **后端版本号**：读取后端代码里的常量。
  3. **数据库当前版本**：执行 `alembic current` 获取当前迁移 revision。
- **作用**：打开软件第一件事就是看时间对不对，如果时间不对，说明没跑新代码。

## 第二部分：排查并修复 M14 前端未生效问题

### 2.1 排查流程
- 检查 `TimelinePage.vue` 是否在 `WorkspacePanel.vue` 或路由中真正挂载。
- 检查 `BookReader.vue` 中的 `<Teleport>` 笔记气泡，是否被其他 CSS 或逻辑拦截，导致页面上根本没渲染出气泡。
- 检查书签的 `created_at` 时间格式化逻辑，确保它真的渲染在 UI 上。
- **如果构建脚本没生效**：检查 `build.ps1`、`package.json` 或 Vite 配置，确保每次打包都会清理旧缓存并生成新文件。

### 2.2 修复具体 Bug
1. **阅读器书签时间与排序**：
   - 侧边栏书签列表按时间倒序（最新在上）。
   - 每条必须显示 `YYYY-MM-DD HH:mm` 格式的时间戳。
2. **阅读器笔记气泡**：
   - 选中文字加笔记后，正文必须出现**浅蓝色波浪线**和 **💬** 图标。
   - 点击 💬 必须弹出气泡（用 `<Teleport>` 挂到 body，计算位置防遮挡，带展开动画）。
3. **时间线与旧功能**：
   - 确保侧边栏的“时间线”入口能点开，里面能看到聚合的数据（如果还没看到，说明聚合逻辑或前端挂载坏了）。
