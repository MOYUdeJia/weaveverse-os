## 1. 目标

把 M10.1 的"整包主题"拆成 **素材 + 槽位 + 预设** 三层：

| 层                 | 说明                                                      |
| ------------------ | --------------------------------------------------------- |
| **素材（Asset）**  | 单件资源：一张图 / 一段视频 / 一套颜色 / 一组图标         |
| **槽位（Slot）**   | 当前使用的选择：界面色 / 桌面背景 / 开屏 / 图标（4 个槽） |
| **预设（Preset）** | 4 个槽的一份快照 + 名字                                   |

**核心原则**：
- 换背景不动颜色，换开屏不动背景
- 全局设置（不透明度、分组栏样式、悬浮球位置等）**不进预设**
- 系统预设**只读**，用户基于它修改只能"另存为"

## 2. 阶段 1：模型重构

### 2.1 数据模型

**素材库**（`data/assets/`）：
```
data/assets/
├── assets.json          ← 素材索引（id、类型、路径、名字）
├── colors/              ← 颜色素材（.wvtheme 格式）
│   └── <id>.json
├── backgrounds/         ← 背景素材（图/视频）
│   └── <id>.png / .mp4 / .webm
├── splashes/            ← 开屏素材（图/视频/Lottie）
│   └── <id>.png / .mp4 / .json
├── icons/               ← 图标包（zip / 文件夹）
│   └── <id>/
└── user/                ← 用户上传的原始文件
    └── <uuid>.<ext>
```

**`assets.json` 结构**：
```json
{
  "colors": [
    {"id": "warm-white", "name": "暖白", "system": true, "path": "colors/warm-white.json"},
    {"id": "sakura", "name": "樱粉", "system": true, "path": "colors/sakura.json"}
  ],
  "backgrounds": [
    {"id": "dragon-bg-1", "name": "龙娘室内", "system": false, "path": "backgrounds/dragon-bg-1.png"}
  ],
  "splashes": [
    {"id": "dragon-splash", "name": "龙娘立绘", "system": false, "path": "splashes/dragon-splash.png"}
  ],
  "icons": [
    {"id": "dragon-icons", "name": "龙娘图标", "system": false, "path": "icons/dragon-icons/"}
  ]
}
```

**预设**（`data/presets/`）：
```
data/presets/
├── presets.json         ← 预设索引
├── warm-white.json      ← 系统预设
├── sakura.json
├── mist-purple.json
└── my-dragon.json       ← 用户预设
```

**预设结构**：
```json
{
  "id": "my-dragon",
  "name": "我的龙娘",
  "author": "用户",
  "system": false,
  "based_on": "dragon-girl",
  "slots": {
    "colors": "dragon-purple",
    "background": "dragon-bg-1",
    "splash": "dragon-splash",
    "icons": "dragon-icons"
  },
  "slot_config": {
    "splash": {"duration": 2, "slogan": "正在编织你的宇宙"},
    "background": {"opacity": 0.85}
  }
}
```

**槽位**（全局当前状态，存在 `appearance.json`）：
```json
{
  "current_preset": "mist-purple",
  "slots": {
    "colors": "mist-purple",
    "background": "mist-purple-bg",
    "splash": "default",
    "icons": "default"
  },
  "dirty": false        // 是否有未保存修改
}
```

### 2.2 兼容现有 `.wvpack` / `.wvtheme`

- **`.wvtheme`** = 一个颜色素材（直接作为一个 colors 类型素材导入）
- **`.wvpack`** = 一个完整预设（导入时把内部的颜色/背景/开屏解构到素材库，生成一个预设）
- **现有系统预设（暖白/樱粉/雾紫/龙娘）**迁移成新格式

### 2.3 后端 API

- `GET /api/assets?type=colors|backgrounds|splashes|icons` — 列出素材
- `POST /api/assets/upload` — 上传素材（支持多文件）
- `DELETE /api/assets/{type}/{id}` — 删除素材
- `GET /api/presets` — 列出预设
- `POST /api/presets` — 创建预设
- `PATCH /api/presets/{id}` — 修改预设
- `DELETE /api/presets/{id}` — 删除（系统预设不可删）
- `POST /api/presets/apply/{id}` — 应用预设
- `GET /api/slots` — 获取当前槽位状态
- `PATCH /api/slots` — 修改单个槽
- `POST /api/presets/export/{id}` — 导出为 `.wvpack`
- `POST /api/presets/import` — 导入 `.wvpack`

### 2.4 未保存提示

**切换预设时**：
```
如果 dirty = true：
  弹窗：
    "当前配置有未保存修改"
    [保存到当前预设]（系统预设时禁用）
    [另存为新预设]
    [放弃修改]
    [取消]
```

**单个槽修改**：
- 立即应用（实时预览）
- 标记 `dirty = true`

**保存**：
- 用户主动点"保存"
- 或切换预设时选择"保存"

## 3. 阶段 2：前端 UI

### 3.1 设置 → 主题

**布局**：

```
┌────────────────────────────────────────────────────────────┐
│ [预设] [素材库] [槽位]                          [保存]      │
├────────────────────────────────────────────────────────────┤
│ 当前预设：樱粉 ⚠️ 未保存                                    │
│                                                            │
│ ┌──────────────────────────────────────────────────────┐   │
│ │ [预设列表]                                            │   │
│ │  暖白                                                  │   │
│ │  樱粉 ✓                                                │   │
│ │  雾紫                                                  │   │
│ │  龙娘                                                  │   │
│ │  我的龙娘（自定义）                                     │   │
│ │  [+ 新建预设]                                          │   │
│ │  [导入 .wvpack] [导出当前]                             │   │
│ └──────────────────────────────────────────────────────┘   │
│                                                            │
│ 槽位（当前）                                                │
│  界面色：[樱粉 ▼] [从素材库选]                              │
│  桌面背景：[无 ▼] [从素材库选]                              │
│  开屏：[默认 ▼] [从素材库选]                                │
│  图标：[默认 ▼] [从素材库选]                                │
└────────────────────────────────────────────────────────────┘
```

**三个 Tab**：
- **预设**：切换、新建、导入导出、删除
- **素材库**：素材列表（按类型分组），上传/删除
- **槽位**：当前四个槽的选择

### 3.2 素材库 UI

**分类 Tab**：颜色 / 背景 / 开屏 / 图标

**每个素材**：
- 缩略图 / 预览
- 名字
- 来源（系统 / 用户）
- 操作：应用到槽、删除（系统素材不可删）

**上传**：
- "添加素材"按钮 → 支持多文件
- 上传到 `data/assets/user/`
- 自动识别类型（图片 → 可做背景或开屏；视频 → 可做背景或开屏；JSON → 颜色）
- 用户选择素材类型

### 3.3 槽位 UI

每个槽一个卡片：
- 当前选用的素材（缩略图 + 名字）
- 点击 → 弹出素材选择器
- 右侧有设置（如开屏的时长、背景的不透明度）

**素材选择器**：
- 列出该类型所有素材
- "上传新素材"
- 点击选中

### 3.4 导入导出

**导出**：
- 生成 `.wvpack`（zip）
- 内含：`manifest.json` + 用户素材 + 系统素材的 id 引用
- 走系统"另存为"对话框

**导入**：
- 选 `.wvpack`
- 检查系统素材 id 是否都存在
- 缺失的系统素材 → 槽位留空，提示用户
- 用户素材解压到 `data/assets/`
- 生成一个用户预设

### 3.5 图标槽（这次做）

**MVP 范围**：
- 图标包 = 一个文件夹或 zip，包含若干 PNG
- 预设携带一个 `icons` 素材 id
- 应用预设时，**不强制替换所有图标**
- 在导航项编辑弹窗里，提供"从图标包选"入口
- 用户主动选

**不做**：
- 图标包的在线商店
- 自动识别图标名

## 4. 阶段 3：系统预设 + 素材获取

### 4.1 系统预设（3 套）

**内置，只读**：

| 预设     | 颜色                | 背景 | 开屏     | 图标 |
| -------- | ------------------- | ---- | -------- | ---- |
| **暖白** | 现有暖白            | 无   | 默认圆标 | 默认 |
| **樱粉** | 现有樱粉            | 无   | 默认圆标 | 默认 |
| **雾紫** | 按银白/淡紫新配一套 | 无   | 默认圆标 | 默认 |

**龙娘**：
- 从 M10.1 的龙娘包**转换**成一个系统预设
- 但**开屏和背景解耦**：
  - 开屏：如果用户提供干净的龙娘图，用它；否则默认
  - 背景：**不用 startup.mp4**（含 Codex 界面）

### 4.2 异环 / 赛尔号：用户本地预设壳

**只创建"预设壳"**，不内置素材：
```json
{
  "id": "yihuan-personal",
  "name": "异环（我的）",
  "system": false,
  "slots": {
    "colors": "yihuan-colors",     ← 颜色可以现配
    "background": null,             ← 空，用户自己填
    "splash": null,
    "icons": null
  }
}
```

**颜色**：agent 根据异环/赛尔号的**公开视觉风格**配一套色（不侵权）。

**素材**：agent 提供**搜索指引**：

```markdown
# docs/ASSET-GUIDE.md

## 异环主题素材来源

- 官方宣传图：异环官网 / 官方微博
- 角色立绘：官方社交账号、Pixiv（搜 "异环"）
- 动态背景：B站相关动态、官方PV截取

## 赛尔号巅峰之战素材来源

- 精灵立绘：B站"摸鱼的橙汁"动态（搜"赛尔号"）
- 官方宣传图：赛尔号官网 / 官方微博

## 使用方法

1. 用户自己下载素材到本地
2. 打开应用 → 设置 → 主题 → 素材库 → 添加素材
3. 选择下载的文件，添加到对应类型
4. 在"预设壳"里把槽位指向该素材
```

### 4.3 版权红线（重申）

**Agent 不能做的事**：
- ❌ 从网上抓取第三方角色素材
- ❌ 去水印
- ❌ 把素材打包进 git 仓库
- ❌ 把素材打包进安装包

**Agent 可以做**：
- ✅ 提供搜索关键词和推荐来源链接
- ✅ 写 `docs/ASSET-GUIDE.md` 指导用户
- ✅ 用户自己下载后，帮忙按格式整理到 `data/`（gitignore）
- ✅ 从**开源/CC0**素材（如 Unsplash、Pexels）提取，用于系统预设

### 4.4 龙娘主题（调整版）

**Agent 引导用户**：
- 提供"如何找一张干净的龙娘立绘"指引
- 用户自己下载 → 放到 `data/assets/user/`
- Agent 帮忙做成开屏素材（静态图 + 淡入淡出）

**不提取 startup.mp4**。
