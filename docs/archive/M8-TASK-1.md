## 2. 范围

### 2.1 修 bug

**Bug 1：背景视频生效时，导航项栏不可见**
- 现象：上传视频背景后，左侧导航项列表看不到了
- 排查方向：视频层 z-index 或 CSS 层级问题，可能盖住了导航栏
- 要求：视频背景正常播放的同时，导航栏正常显示

**Bug 2：分组栏"名字浮出"样式重做**
- 期望形状：圆形图标 + 向右扩展的**胶囊**（左圆 + 右半圆）
- 颜色：与分组栏背景一致
- 覆盖在导航项栏上方，不推栏
- 动画：悬停时名字带 200-300ms 滑动展开
- 做不好就删掉这个样式

**Bug 3：便携笔记标签同步**
- 现象：从便携笔记浮层添加标签后，收件箱不刷新
- 要求：保存后立即刷新收件箱

**Bug 4：便携笔记标签溢出**
- 现象：标签满了超出容器宽度
- 要求：支持左右滑块

**Bug 5：音乐播放/暂停按钮**
- 现象：用文字（如"播放"/"暂停"）
- 要求：换成图形符号（▶ / ⏸ 用 SVG 或 Unicode）

### 2.2 图片库

**数据表**（新建，需要迁移）：
- `photo_library` 表：id、filename、note、added_at
- M8.1 只做单相册（默认库）

**页面类型**：
- 注册 `photo_library` 为系统页（layer: core, multi_instance: false）
- 通过"新建系统页"入口创建
- 创建后归入系统分组

**入口**：
1. 图片库页面 → "上传" → 自动进库
2. doc 里点图片 → 右键 → "加入图片库"
3. **重要**：从 doc 拖入的图**默认不进库**

**功能**：
- 网格 / 列表展示
- 点击 → 大图预览
- 预览里"保存到本地"（原图）
- 删除（从库里移除，**不删附件文件**）
- 空库显示"暂无图片"

### 2.3 不要做

- 不做多相册（M8.2）
- 不做 AI、语音、私有云（M8.2+）
- **STT 先用本地 Whisper.cpp，不做云端 API 集成（阶段 2 再处理）**
- 不引 UI 组件库、TypeScript
- 不改分组系统核心、书架、阅读器

### 系统钥匙串
- API Key 等敏感信息存**系统钥匙串**（Windows Credential Manager / macOS Keychain）
- 由操作系统负责加密和用户隔离，每个用户独立存储、独立解密
- 应用只需调用系统 API 存取，不自己实现加密
- 后续如果其他用户使用，他们的凭据天然受各自系统账户保护
