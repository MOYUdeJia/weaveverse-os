## 第一部分：图片库 UI 修

### 1.1 "铺满"改成大图流

**现状**：之前实现的"铺满"是"网格无空隙紧挨着"。

**用户要的**：**大图流**——每张图**横跨整个相册宽度**，垂直堆叠，上下滚动。

**实现**：
- 视图名称改为"大图流"（或"单栏"）
- 每张图宽度 100%，高度按原图比例自适应
- 图片之间留一点小间距
- 上下滚动查看
- 点击进入大图查看
- 删掉原来的"网格无空隙"实现

### 1.2 相册默认颜色扩展

**现状**：默认色太少。

**要求**：扩展到 **12-16 种**，覆盖色相环主要区间（红、橙、黄、绿、青、蓝、紫、粉、棕、灰、黑、白，每种带亮/暗变体）。色值沿用现有主题色板风格。

### 1.3 新建相册按钮与普通相册区分

- 新建相册按钮：**虚线边框 + "+"图标**
- 普通相册标签：**实心色点 + 名字**
- 让用户一眼看出"新建入口"和"已有相册"

### 1.4 按钮视觉区分

| 类型     | 按钮                          | 视觉                              |
| -------- | ----------------------------- | --------------------------------- |
| 主操作   | 上传、新建相册                | 实心、强调色                      |
| 模式切换 | 选择/取消、网格/自适应/大图流 | 描边或图标 + 文字，能看出当前选中 |
| 次要操作 | 未分组筛选、全选、取消选择    | 文字按钮或小图标                  |

## 第二部分：AI 操作数据（Function Calling）

### 2.1 工具清单

| 工具                | 作用                            |
| ------------------- | ------------------------------- |
| `create_page`       | 创建新导航项（积木页 / 专用页） |
| `search_items`      | 搜索导航项、书籍、分组          |
| `get_page_content`  | 读取某页的内容                  |
| `create_quick_note` | 创建速记                        |
| `list_groups`       | 列出所有分组                    |
| `create_group`      | 创建分组                        |

**不做**：修改现有内容、删除、移动。

### 2.2 后端：function calling 循环

- AI 返回工具调用 → 执行 → 结果回给 AI → AI 生成最终回复
- 支持多轮工具调用
- 每个工具的实现**走现有 crud 层**，不重写逻辑

### 2.3 系统提示词更新

- 告诉 AI 能调用哪些工具
- 工具的能力边界
- **先确认再操作**（如"要创建一个 XX 页面吗？"）

### 2.4 前端展示

- 聊天里显示"正在创建页面..."之类状态
- 工具返回后显示结果
- 创建页面后提供"前往查看"链接
- **不要让 AI 自动跳转**，用户自己点

### 2.5 安全

- 工具调用前让用户确认（首次调用）
- 或者：设置里"AI 操作"开关，默认关
- **你判断哪个方案更合适**

## 第三部分：IDEA 栏

### 3.1 页面类型

注册 `idea_box` 为系统页（layer: core, multi_instance: false）。
- 通过"新建系统页"入口创建
- 归入系统分组
- 默认图标 💡

### 3.2 数据模型

**新表 `ideas`**：
- id
- title（可选）
- content
- tags（JSON 数组）
- created_at
- updated_at

### 3.3 界面

- 顶部：搜索框 + 标签筛选 + "新建点子"按钮
- 列表 / 卡片网格（你选）
- 每条：内容 + 标签 + 时间 + 编辑/删除按钮
- 点击标签 → 筛选

### 3.4 AI 增强

- "总结这个点子"按钮 → AI 生成摘要
- "自动贴标签"按钮 → AI 提取关键词作为标签
