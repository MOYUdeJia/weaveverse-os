## 第一部分：救火（阅读器）

### 1.1 修复无法选中文字与无右键菜单
- **Bug**：M12 的阅读器（EPUB/TXT）完全无法用鼠标选中文字，右键也没有菜单。
- **要求**：排查 CSS（是否被 `user-select: none` 拦截）或事件冒泡拦截。必须让文本可选中，并在选中后正常弹出定制右键菜单。

### 1.2 重构书签与定位逻辑
- **现状**：书签不清晰，不知道怎么定位。
- **要求**：
  - 侧边栏书签列表按时间**倒序**（最近的在最上面）。
  - 书签需显示：**时间（YYYY-MM-DD HH:mm）**、原文摘录、用户添加的说明文字。
  - **添加书签时**：弹窗让用户填写备注（可选）。
  - **点击书签时**：跳转到对应位置，且**在正文中高亮/标出该位置**（用个显眼的背景色或边框）。

## 第二部分：UX 修复（核心体验）

### 2.1 主题与素材库排版重构
- **预设列表**：修复“编辑”和“删除”按钮不对齐、格式乱的问题。
- **编辑预设（关键）**：点击“编辑”后，**必须弹出一个模态框（Modal）**，不要在最下面展开！模态框内：
  - 四个槽位（色/背/开/图）默认**收起**，只显示当前选中的素材缩略图。
  - 用户点击该行时，再展开选择器（或弹二级框）。
  - 字体需要有层级（标题大、说明小、选项加粗）。
- **素材库**：
  - **增加默认预览**（图片显示图，视频显示首帧，颜色显示色块）。
  - 取消点击即选中，**增加类似相册的“选择”按钮**。进入选择模式后，才能多选。
  - **删除必须弹确认框**：“确定删除选中的 N 个素材吗？系统素材不可删除。”

### 2.2 悬浮球右键菜单逻辑
- **修复**：“播放方式”子菜单不能一直铺开。
- **要求**：遵循标准交互，**鼠标悬停或点击**时才展开子菜单，鼠标移开或点空白处收起。控制好延迟容差。

### 2.3 图标槽与预设的同步逻辑
- **要求**：
  - 在导航项或分组编辑里裁剪/上传的新图标，**自动保存到素材库**。
  - **槽位隔离**：图标绑定（哪个导航项用哪个图）属于当前预设的快照。如果切到一个没改过图标的预设，显示系统默认 Emoji。
  - 确保这套逻辑在切换预设时不会串台。

## 第三部分：UI 大修（使用 Skill）

### 3.1 调用 Skill 重塑设置界面
- **任务**：使用 `frontend-design` 和 `design-taste-frontend` 审视并重构整个设置界面（包括主题、通用、隐私、AI 等所有 Tab）。
- **要求**：
  - 抛弃现在“全堆在一起、字体一样大”的毛病。
  - 建立清晰的视觉层级：模块分割线、卡片式包裹、标题加重、次要文字变灰。
  - 按钮样式统一（主操作、危险操作、取消）。
  - 不要花哨，要求“现代、干净、留白合适”。
  - **自主判断**：如果发现其他界面（如图片库、阅读器侧边栏）也有类似 UI 问题，一并顺手改掉。
