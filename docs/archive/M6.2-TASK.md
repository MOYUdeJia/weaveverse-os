## 2. 范围

### 2.1 doc 图片尺寸控制

**现状**：图片默认随界面尺寸充满。

**要求**：
- **默认行为保持**：随界面尺寸自适应，尽量充满
- **右键图片 → 弹出编辑菜单**：
  - 缩放（拖拽把手调整，或输入百分比）
  - 可选：对齐（左/中/右）、圆角
- **不做**：复杂的图片编辑器（滤镜、裁剪等）

**技术选型**：TipTap 有图片扩展，你查是否有现成的 resize 扩展。如果没有，用 `tiptap-extension-resize-image` 或自建。说明理由。

### 2.2 doc 文件/链接打不开

**文件**：
- 现在上传后点击没反应
- 应该：点击 → 用系统应用打开（PDF、图片、Office 都走系统）
- 后端加接口：`GET /api/blocks/{id}/files/{filename}/open` 或前端用 pywebview `js_api.open_file`
- 如果 WebView 里打不开，先记录已知问题，浏览器开发模式至少能下载

**链接**：
- 现在点击没反应（M2 时是能打开的）
- 排查：是 TipTap 拦截了点击，还是 pywebview 外链桥失效
- 修好：点击链接 → 系统浏览器打开

### 2.3 doc 拖入多图逻辑

**现状**：拖一张图后不点屏幕，继续拖第二张会替换第一张。

**要求**：
- 按鼠标**放置位置**插入
- 连续拖入多张图，各就各位

**排查方向**：TipTap 的 drop 事件位置计算，或拖拽上下文状态未清除。

### 2.4 doc 右键菜单精简

去掉"粘贴截图"项（Ctrl+V 已覆盖）。

保留：
- 剪切 / 复制 / 粘贴 / 全选
- 添加链接
- 添加图片
- 添加文件
- 撤销 / 重做

### 2.5 笔记取色面板加标准色

Pickr 面板里的 hex 输入**保留**（不用删），但**加一排常用标准色**：
- 黑、白、红、橙、黄、绿、青、蓝、紫、灰
- 点一下即选中
- 面板布局：标准色在上，色相/饱和度/hex 在下

### 2.6 全局搜索

**入口**：
- 快捷键 `Ctrl+K`（macOS 是 `Cmd+K`）
- 或顶栏一个搜索图标

**行为**：
- 弹出浮层，输入即时出结果（300ms 防抖）
- 结果分类展示：导航项 / 分组 / 书籍 / 区块内容
- 点击结果 → 跳转到对应页面
- `Esc` 关闭

**搜索范围**（M6.2 第一版）：
- 导航项标题 + 图标
- 分组名
- 书籍标题 + 作者
- 区块内容（markdown 文本、待办项、链接标题、书籍封面标题等）

**实现方式**（你选，说明理由）：
- A. 前端本地索引（数据量小时快，但需加载全部数据）
- B. 后端搜索接口（`GET /api/search?q=xxx`），前端只发请求
- C. 混合（导航项/分组前端，区块内容后端）

**推荐 B**。理由：区块内容可能很大，前端全量加载会卡；后端 SQLite 可以直接 LIKE 或 FTS。

**不做**：
- 不做模糊纠错
- 不做同义词
- 不做搜索历史（M6.3 可选）

### 2.7 便携笔记

**入口**：
- 全局快捷键 `Ctrl+Shift+N`（macOS 是 `Cmd+Shift+N`）
- 或顶栏一个"快速记录"按钮

**行为**：
- 弹出浮层，输入框自动聚焦
- 输入内容 + 选分类（或输入 `#标签`）
- `Enter` 保存，`Esc` 取消
- 保存后浮层关闭

**存哪里**（你定，说明理由）：
- A. 存到一个专门的"收件箱"页面（自动创建）
- B. 存到用户指定的页面
- C. 存到数据库 `notes` 新表（待整理）

**推荐 A**：用户不用配置，笔记落到一个固定位置，之后手动整理。符合"快速记录，后续归档"的用法。

**不做**：
- 不做 AI 自动分类（M7+）
- 不做多字段输入（标题、正文、标签分开）
- 只做：一段文本 + 可选分类

### 2.8 不要做

- 不做 M7 的主题 / 音乐 / 首次说明
- 不做 IDEA 栏
- 不改分组系统核心、书架、阅读器
- 不引 UI 组件库、TypeScript
- 不做截图粘贴（已有）
