# Weaveverse OS · M14.2 任务书

> 承接 M14.1。读 `docs/HANDOFF.md`，再读本任务书。
> M14.2 是纯修复版本，不引入新功能（透明玻璃、番茄钟悬浮窗等在 M15 做）。

---

## 1. 修复阅读器 UI
- **书签侧边栏**：标题内容限制显示 2 行（超出用省略号），备注内容全显。两者用灰度和字号做区分。
- **笔记气泡**：设置 `max-height: 300px; overflow-y: auto;`，确保笔记再长也不会越界，气泡内可滚动。

## 2. 修复时间线
- **滚动**：时间线页面加上 `overflow-y: auto`，数据多时可向下滚动。
- **路由状态**：使用 `keep-alive` 或记录滚动位置，确保从时间线点进详情页再返回时，位置不丢失。

## 3. 修复数据目录迁移
- 在迁移逻辑中，排除 `whisper_models/`（太大）和 `*.pre-m5.db`（历史备份），只迁移核心数据库和附件。

## 4. 增加自动验收脚本
- 在项目根目录新建 `scripts/verify.py` 或 `.ps1`。
- 功能：检查前端 `dist` 是否存在且最新，后端 API 是否存活，数据库 Revision 是否最新。
- 输出：生成 `docs/REPORT.md`，包含上述环境健康状态。

## 5. 生成应用图标
- 在 `frontend/public/` 或 `backend/data/` 生成一个 `icon.svg`（按提示词生成莫比乌斯环），并确保 pywebview 的窗口图标使用它。

---

## 输出要求
1. 文件树变化
2. M14.1 → M14.2 修复清单
3. 自动验收脚本的运行结果
4. 追加 `docs/VERSIONS.md`
