## 第一部分：阅读器深度打磨

### 1.1 修复颜色系统串台
- **现象**：选中文字后，无论选高亮还是划线，颜色全部变成了金色。下划线的颜色也全变成了高亮背景。
- **要求**：
  - 排查 CSS 变量或内联样式的覆盖问题（可能是 epub 自身 class 覆盖了你的自定义 class，或者样式注入优先级不够）。
  - 确保 4 种颜色（黄、绿、蓝、红）独立生效。
  - 确保“高亮（背景色）”和“下划线（底部线条）”样式不冲突。

### 1.2 右键菜单与侧边栏区分
- **右键菜单**：将“高亮”和“划线”在视觉上用分割线隔开，不要混在一起。
- **侧边栏列表**：
  - 在侧边栏顶部增加**筛选器（Tabs 或 胶囊按钮）**：`全部 / 高亮 / 划线 / 笔记 / 书签`。
  - 列表项要**按文中出现的位置排序**（先按章节索引，再按字符偏移量），**不要按添加时间倒序**。
  - 列表左侧用一条粗的彩色边框区分类型：高亮黄、划线绿、笔记蓝、书签红。

### 1.3 书签交互重构（选段模式）
- **现状**：只能加单点书签，且没有明显的高亮。
- **要求**：
  - 点击“添加书签”按钮后，进入**“标记模式”**（鼠标指针变为特殊样式，如十字或书签图标）。
  - 用户在正文中**选择一个段落**（或任意文本区间）。
  - 松开鼠标后，该段落**左侧/右侧出现一个书签小图标**，并弹出输入框让用户填备注。
  - 侧边栏书签列表点击时，**整段文字出现短暂的暖黄色高亮闪烁（停留 1 秒后消失）**。

## 第二部分：设置界面细节修复

- **删除预设**：补充确认弹窗（“确定要删除预设 XXX 吗？”）。
