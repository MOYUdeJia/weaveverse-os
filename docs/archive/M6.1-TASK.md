## 1. 目标

把 doc 专用页从"纯 Markdown 文本编辑"升级为"富文本编辑器"，支持：
- 常用排版（标题、粗体、斜体、下划线、列表、表格、代码块）
- 快捷键工具栏
- 右键菜单（复制/粘贴/全选/添加链接/添加图片/添加文件/粘贴截图）
- 粘贴截图直接插入

顺手修：笔记（plain）的颜色选择器回退问题。

---

## 2. 范围

### 2.1 doc 编辑器换库

**当前**：纯 markdown 文本 `{text: "..."}`，分栏视图

**改为富文本编辑器**。候选库：

| 库          | 特点                                    | 备注   |
| ----------- | --------------------------------------- | ------ |
| **tiptap**  | Vue 3 官方支持、插件丰富、Markdown 友好 | 推荐   |
| ProseMirror | 底层、灵活、工作量大                    | 备选   |
| Milkdown    | Markdown 原生、较新                     | 备选   |
| Quill       | 老牌、Vue 支持需包装                    | 不推荐 |

**你定，说明理由。**

### 2.2 快捷键工具栏

放在编辑器**上方固定**（或下方，你选）：

- **H1 / H2 / H3**：一键设标题
- **粗体 / 斜体 / 下划线 / 删除线**
- **有序 / 无序列表**
- **代码块 / 行内代码**
- **引用块**
- **表格**
- **分割线**
- **链接**
- **撤销 / 重做**

图标用 emoji 或 SVG 都行，不要引图标库。

### 2.3 右键菜单

参考 macOS 风格：

- 复制 / 剪切 / 粘贴
- 全选
- 添加链接
- 添加图片（上传或粘贴）
- 添加文件（上传）
- 粘贴截图（剪贴板读取）
- 撤销 / 重做

**粘贴截图**：监听 `paste` 事件，如果剪贴板有图片，上传到 `backend/data/attachments/`（复用现有接口），插入到光标处。

### 2.4 顺手修：笔记颜色选择器

**问题**：现在只有两个滑块，用户反映不如之前好用。

**要求**：
- 至少支持：色相（hue）+ 饱和度 + 亮度
- 或者用标准 hex 输入 + 颜色面板
- 面板打开后不自动关闭
- 你判断用哪个组件，说明理由

**候选**：
- `vue-color`：功能全，较老
- `@simonwep/pickr`：现代，功能全
- 继续用 `vanilla-colorful` 但配置成 hex 输入版

### 2.5 数据格式

**当前**：doc 存 `{text: "markdown字符串"}`

**换富文本后怎么存**，你定，说明理由。候选：

- A. 继续存 markdown（tiptap 加 markdown 扩展，双向转换）
- B. 存 HTML（简单，但可能含脏标签，需 DOMPurify）
- C. 存 tiptap JSON（最原生，展示时需要 render）
- D. 存 JSON + 导出 markdown 备份

**建议 A 或 C**。**关键要求**：现有 doc 页面的 `{text}` 数据必须能正常打开（迁移或兼容读取）。

### 2.6 不要做

- 不做全局搜索（M6.2）
- 不做便携笔记（M6.2）
- 不做首次使用说明（M7）
- 不改 plain / bookmarks / canvas 的核心逻辑（颜色选择器除外）
- 不改分组系统、书架、阅读器
- 不引 UI 组件库、TypeScript
