## 第一部分：密码系统

### 1.1 文案 & UI 小修

- 分区改名键：`改名` → `重命名`
- 复制密码图标：像锁，换成更明显的"复制"符号
- 账密排版：**显得太拥挤**，优化间距和对齐

**具体怎么优化由你判断**，目标是"整齐、不挤、一眼看清"。

### 1.2 改密码后强制重新解锁

**改动**：修改安全密码成功后，**本会话的解锁状态立即失效**。

- 需要重新输入新密码才能访问密码库 / 备份
- 理由：改密码是敏感操作，重新验证一次更安全

### 2.2 面板展开策略（给出具体数值）

**位置判断**（按球的水平位置）：
```
球 x 坐标 / 窗口宽度 < 0.30  → 左侧区域
球 x 坐标 / 窗口宽度 > 0.70  → 右侧区域
其他                          → 中间区域
```

**展开方向**：

| 位置     | 方向               |
| -------- | ------------------ |
| 中间区域 | 从球向左右两边展开 |
| 左侧区域 | 向右侧展开（单侧） |
| 右侧区域 | 向左侧展开（单侧） |

**展开长度**：

| 情况       | 长度公式                                                |
| ---------- | ------------------------------------------------------- |
| 从中间展开 | `总长 = min(窗口宽 × 0.60, 球左右两侧较小可用空间 × 2)` |
| 从一侧展开 | `总长 = min(窗口宽 × 0.45, 该侧可用空间 - 24px)`        |

**边距**：展开后的胶囊距离窗口边缘至少 16px。

**位置切换时**：重新计算，动画过渡。

**设置**：
- 自动（默认）：按上面规则
- 强制从中间
- 强制从一侧

**如果按照上面数值做出来不好看**：
- 允许你微调数值
- 但必须保持"先算可用空间，再定方向 + 长度"的原则

### 2.3 视觉细节

**面板与球的连接**：
- 球与胶囊**共用底色**
- 球在端点时，胶囊伸到球心，靠球的一端被圆盖住
- 球在中间时，胶囊从球后穿过，**球在胶囊上层**
- 视觉上无缝

**进度条与球的关系**：
- 进度条在胶囊上下边框
- **经过球时，进度条沿球的轮廓"凸起"绕过**（不是直线穿过）
- 效果：球像进度条上的一个节点/凸起
- 类似"线串珠子"的视觉

**球在面板展开时**：
- 球显示播放/暂停键
- 与面板同色

### 2.4 按键尺寸

**靠近边缘时按键不要太挤**：
- 缩小按键尺寸（如从 36px 到 32px）
- 或调整间距
- 或让按键**弧形展开**（不是固定位置）

**你判断最优方案，目标是"边缘时也能点到"**。
