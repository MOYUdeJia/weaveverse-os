## 1. 目标

修复 M4 试用中发现的问题，并优化左侧导航栏图标体验。

---

## 2. 范围

### 必须做（Bug 修复）

**Bug 1：最近阅读卡片只显示进度条，不显示百分比数字**

- 位置：书架"最近阅读"卡片
- 修改：进度条旁加百分比文字（如 `45%`）

**Bug 2：单实例页面类型可以建多个**

- 现象：建两个"书架"项，右侧显示同一批书
- 涉及类型：`bookshelf`、`vault`、`idea_box`、`future_plan`、`habit_tracker`
- 修改：
  - 后端：创建 nav_item 时，若 page_type 是单实例类型且已存在同类项 → 返回 409
  - 前端："+"里若该单实例类型已存在 → 不显示该选项
  - 已有重复项时：让 agent 决定是否自动清理，列出方案

### 应该做（导航图标优化）

**Bug 3：导航图标输入多字符会溢出**

- 现象：icon 字段输入多个字符，布局错乱
- 修改：限制显示宽度，溢出截断或显示占位

**优化：提供默认图标库**

- 侧边栏编辑弹窗里，icon 从"纯文本输入"改为"文本输入 + 图标选择器"
- 图标选择器提供一批默认图标（emoji 或内置 SVG）
- 用户点选后填入 icon 字段

**优化：支持上传自定义图标**

- 上传图片作为图标
- 提供固定尺寸裁剪窗口（建议 1:1，尺寸你定，说明理由）
- 裁剪后的图片存到 `backend/data/icons/`
- `nav_items.icon` 存引用（前缀标识，如 `@file:xxx.png` 或新增 `icon_type` 字段）
- **如果这部分工作量太大**：先做默认图标库，上传功能拆到 M4.2。列出你的判断

### 不要做

- 不做书架自定义封面（记到 FEATURES.md，后续版本）
- 不做书架分类（文学/科技/自传，记到 FEATURES.md，后续版本）
- 不碰阅读器逻辑、区块系统、模板系统
- 不引入 UI 组件库、TypeScript
- 不引图标库（emoji 直接填，或用现有素材，不装 `lucide` 之类）

---

## 3. 关键约定

- **加新功能不改老代码**：图标相关逻辑集中在一处
- **文件存储规范**：图标存 `backend/data/icons/`，`.gitignore` 排除，留 `.gitkeep`
- **单实例校验是后端强制的**：不能只做前端隐藏
- **icon 字段兼容性**：M4 之前的 icon 都是纯字符串（emoji），改动后老数据必须还能正常显示

## 4. 验收标准

### 4.1 Bug 修复验收

- [ ] 最近阅读卡片显示百分比数字
- [ ] 建一个书架项后，"+"里不再出现"书架"选项
- [ ] 后端直接调 `POST /api/nav` 建第二个书架 → 返回 409
- [ ] 其他单实例类型（idea_box、vault、future_plan、habit_tracker）同样受限
- [ ] 老数据（无 icon 的、多字符 icon 的）都能正常显示，不溢出

### 4.2 图标优化验收

- [ ] 编辑导航项时，能打开图标选择器
- [ ] 从默认图标库选一个 → 显示为导航图标
- [ ] （如果做了上传）上传图片 → 裁剪 → 保存 → 显示为导航图标
- [ ] （如果做了上传）上传的图标重启后还在
- [ ] 删除导航项时，其上传的图标文件也被删除

### 4.3 兼容性验收

- [ ] M4 的书架功能正常（导入、阅读、进度）
- [ ] M2/M3 的页面、区块、模板正常
- [ ] 老导航项正常
