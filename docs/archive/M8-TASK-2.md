## 2. 修 bug

### 2.1 分组栏"名字浮出"方背景残留

**现象**：分组图标外圈有个方形背景，浮出成胶囊后，方形背景还在下面。

**要求**：删掉方形背景，图标本身用圆形或无背景。浮出成完整的圆形 + 胶囊。

### 2.2 标签系统提示

**a. 常用标签上限 6 个**
- 想加第 7 个时 → 提示"最多 6 个常用标签，可先删一个"（非侵入式，不用弹窗）

**b. 添加重复标签**
- 输入已存在的标签 → 提示"已存在"，不静默忽略

**c. 非侵入式提示**
- 所有这类提示用**顶部浮出 / 中部短暂显示**的样式
- 不弹确认框
- 2 秒后自动消失

### 2.3 标签历史池（新增）

**痛点**：速记打过的标签，下次要重新输入。

**实现**：
- 速记保存时，把标签追加到 `backend/data/quick_tags.json` 的 `history` 数组（去重，按最近使用排序）
- 速记浮层里：
  - 上方：常用标签（最多 6 个，快捷显示）
  - 下方：一个"更多"或"历史"按钮，展开显示历史池
  - 历史池里的标签可点击直接使用
  - 历史池里的标签可"设为常用"（如果常用未满 6 个）
- 历史池上限：保留最近 100 个
- 常用标签保持独立，仍是 6 个上限

**数据格式**：
```json
{
  "common": ["工作", "生活", "灵感", "待办"],
  "history": ["游戏", "学习", "阅读", ...]
}
```

**兼容**：如果 `quick_tags.json` 是旧格式（只有数组），迁移到新格式。

### 2.4 doc 里"加入图片库"的右键菜单

**现象**：右键菜单分隔线和"缩放比例"放一起了。

**要求**：修复菜单分组。

### 2.5 doc 里"加入图片库"缺相册选择 + 无成功提示

## 3. 图片库增强

### 3.1 相册功能

**新增表 `photo_albums`**：
- id
- name
- cover_filename（可选）
- is_private（bool，默认 false）
- sort_order
- created_at

**`photo_library` 表加字段**：
- `album_id`（外键，可空表示未分类）
- `display_name`（用户编辑后的显示名，保存本地时用这个名字）

**功能**：
- 创建 / 编辑 / 删除相册
- 图片可移动到相册
- 顶部 Tab 切换相册（"全部" + 各相册）
- 删除相册时，图片回到"未分类"（不删图片）

### 3.2 重命名

- 图片可重命名（改 `display_name`）
- 保存到本地时用 `display_name`，不是原文件名

### 3.3 隐私相册

**需求**：单个相册可标记为"隐私"，打开需密码。

**实现**：
- 相册有 `is_private` 标记
- 首次设为隐私时，设一个密码
- 密码存哪：**先用系统钥匙串**（如果阶段 2 不好做，先哈希存 `appearance.json`，M9 迁移到钥匙串）
- 打开隐私相册时，弹密码框
- 解锁后本次会话内免密码，切换相册后重新锁

**说明**：这不是真正的加密存储（文件还是明文），只是访问控制。真正的加密留 M9。

### 3.4 多选操作

- 网格视图支持多选（长按 / Ctrl+点击 / 勾选）
- 批量删除
- 批量移动到相册
- 顶部显示"已选 N 张"+"删除"+"移动"按钮

### 3.5 排列方式

**新增两种视图**：
- **网格**（当前）：固定尺寸
- **自适应**（类似苹果相册）：按原图比例，大小不一，紧密排列
- **列表**：当前已有

自适应布局实现：用 **CSS Grid + `grid-auto-rows` + `aspect-ratio`**，或 **Masonry 布局库**（如 `masonry-layout`）。你判断哪个好。

### 3.6 大图显示

- 点击图片 → 全屏预览
- 图片**尽可能铺满屏幕**，跟随窗口大小
- 保持原图比例（不拉伸）
- 左右方向键切换上/下一张
- Esc 关闭
- 保存到本地按钮
