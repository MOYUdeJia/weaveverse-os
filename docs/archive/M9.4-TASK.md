## 1. 修 bug

### 1.1 进度条必须绕过球，不能穿过（所有位置）

**现状**：
- 球在中间：进度条沿球凸起 ✅（M9.3 已做）
- 球在端点：进度条**直穿**球 ❌

**要求**：
- **所有位置**，进度条都要**沿球的圆弧凸起绕过**，不穿过球内部
- 球在端点时，进度条从球的一侧进，沿球的上半圈（或下半圈）绕过，再从另一侧出
- 视觉上：球是进度条上的一个节点，线在球处"拱"一下

**禁止**：任何情况下进度条穿过球内部。

### 1.2 从一侧展开没生效

**现状**：球靠左（<30%）或靠右（>70%）时，本应"向一侧展开"，但**实际没有按规则执行**。

**排查**：
- 计算逻辑是否真的被执行
- 是否仍按"从中间向两边"公式走了
- 设置里选了"自动"时，是否真的按横坐标分区

**要求**：
- 球 x/w < 0.30 → 向右单侧展开
- 球 x/w > 0.70 → 向左单侧展开
- 0.30 ≤ x/w ≤ 0.70 → 从中间向两边
- 设置里"自动"必须严格执行以上规则

**如果 M9.3 的代码里"单侧展开"分支没被触发**：
- 找根因
- 修好
