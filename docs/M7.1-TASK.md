## 2. Bug 清单

### 2.1 背景图上传后没反应

**现象**：点上传 → 弹文件选择框 → 选文件 → 点确定 → 界面没提示，也不显示文件名。

**排查方向**：
- 前端上传后有没有收到响应？控制台有没有报错？
- 后端 `/api/appearance/...` 上传接口有没有被调用？
- 上传成功后，前端有没有更新显示？
- 上传失败时有没有错误提示？（用户反映没有任何反馈）

**要求**：
- 上传成功 → 显示文件名 + 预览
- 上传失败 → 显示错误原因（文件太大？格式不支持？）
- 视频背景同理

**如果根因复杂**：先让用户看到"失败原因"，再修上传本身。

### 2.2 分组栏"名字浮出"样式重做

**现状**：
- 颜色跟原分组图标周围颜色不一样
- 没有动画，直接显示
- 不是"浮出"，是"直显"
- 形状不对

**期望**：
- 分界线不动
- 悬停的分组名**从图标处向右滑出**（带动画，约 200-300ms）
- 形状：**左边半圆 + 右边长方形**（类似 Telegram 的小气泡 tooltip）
- 颜色跟分组栏背景一致或接近
- 圆角自然

**做不好就删掉这个样式**——保留"推栏式"和"图标在上"两种。

### 2.3 速记：时间戳 + 标签丢失

**现象**：
- 速记条目**没有时间戳**
- 右侧**标签也没显示**

**排查方向**：
- VERSIONS 说时间戳写进 `at` 字段，前端渲染了吗？
- 标签数组存进数据库了吗？前端读了吗？
- 是主题相关 bug（某个主题下文字和背景同色）还是渲染 bug？

**要求**：
- 时间戳显示在右下角小字
- 标签显示在条目里，蓝色发光

### 2.4 速记时加不了标签

**现象**：`Ctrl+Shift+N` 呼出速记浮层后，**没法选标签**。只有在收件箱页面里才能加标签。

**要求**：速记浮层里也能选/加标签（最多 3 个）。

### 2.5 收件箱标签筛选 bug

**现象**：选中 `#工作` 标签 → 删掉其中一条 → 列表**还显示 `#工作` 筛选结果**，需要切别的标签再取消才刷新。

**要求**：删除后立即刷新，如果该标签下已无内容，显示空状态。

### 2.6 筛选栏加"全部"按钮

**现状**：收件箱顶部有常用标签筛选，但没有"全部"。

**要求**：
- 加一个"全部"按钮
- 用**不同颜色**与标签区分（比如灰色 vs 蓝色标签）
- 点击显示所有速记

### 2.7 收件箱不自动刷新

**现象**：在收件箱里添加速记后，列表**不刷新**，需要切换到其他导航项再切回来才看到新条目。

**要求**：添加后立即刷新。

### 2.8 音乐播放器重做

**现状问题**：
- 界面丑
- 占位置
- 不能收起
- 悬空样式不好看
- 没有歌单

**期望**：
- 好看、流畅、简约、不碍眼
- **可收起**（折叠成小图标或窄条）
- 有**歌单**（列表、切换）
- 位置设置保留（上/下/右下）

**风格**：不指定具体风格，让 agent 自己判断"简约不碍眼"的实现。可以参考：
- Apple Music 的极简底栏
- Spotify 的紧凑播放条
- 网易云音乐的沉浸式

**关键约束**：
- 不引 UI 组件库
- 播放逻辑保持（Plyr 或换成更好看的组件，你判断）
- 不丢现有功能（播放/暂停/切歌/进度/音量）
