## 1. 目标

把左侧导航改造成三栏结构：**分组栏 + 导航项栏 + 工作区**。

分组栏借鉴 Telegram：
- 默认 48px 宽，只显示分组图标
- hover 时向右展开到 200px，显示图标 + 名字
- 设置里可勾选"默认显示名字"（展开模式）

分组支持：新建、编辑、删除、拖拽排序、跨分组移动导航项。

顺手修 M4.1 遗留：图标裁剪改 QQ 头像逻辑（不露白底、有边界约束、有缩放上下限）。

## 4. 数据模型

### 表 `groups`（新增）

字段由 agent 设计。基本要求：
- id（主键）
- name（分组名，非空）
- icon（复用 nav_items.icon 格式，支持 emoji + @file:xxx）
- sort_order
- created_at / updated_at

### 表 `nav_items`（修改）

- 新增 `group_id`（外键，级联删除）
- 新增 `pinned`（bool，默认 false）
- 现有 `sort_order` 保留

### `page_types.py` 加分组导览类型

```python
"group_overview": {
    "layer": "core",
    "label": "分组导览",
    "multi_instance": False,
    "default_blocks": [],
}
```

**注意**：这是 M5 唯一新增的页面类型。它由系统自动创建，不出现在"新建"菜单。

## 5. 接口契约（你定，但保持 RESTful）

必备接口：
- `GET /api/groups` — 列表（含每个分组的导航项数）
- `POST /api/groups` — 创建（自动创建 group_overview 页面）
- `GET /api/groups/{id}` — 详情（含该分组所有 nav_items）
- `PATCH /api/groups/{id}` — 更新（name / icon）
- `DELETE /api/groups/{id}` — 删除（一并删除其 nav_items，但"系统"分组不可删）
- `POST /api/groups/reorder` — 排序

- `GET /api/nav?group_id={id}` — 某分组下的导航项
- `PATCH /api/nav/{id}` — 更新（支持改 group_id 实现移动）
- `PATCH /api/nav/{id}/pin` — 置顶切换

**约束**：
- 单实例类型（bookshelf / vault / idea_box / ...）自动归入"系统"分组
- "系统"分组不可删除、不可重命名
- 同分组内 title 唯一（大小写不敏感、去空格比较）

## 6. 前端三栏布局

```
┌────┬──────────┬─────────────────────────┐
│分组│ 导航项    │                         │
│栏  │ 列表      │      工作区              │
│48px│ 240px    │                         │
│或  │          │                         │
│200px          │                         │
└────┴──────────┴─────────────────────────┘
```

### 分组栏

- 默认 48px 宽，只显示图标（32×32 居中）
- hover 时展开到 200px，显示图标 + 名字
- 展开有 300ms transition
- 点击图标 → 切换分组 → 中间栏刷新
- 底部分隔线 + 一个"+"按钮（新建分组）
- 窗口宽度 < 900px 时强制收起

### 导航项栏

- 240px 宽
- 顶部：分组名 + 编辑按钮
- 列表：导航项（含置顶区）
- 每项 hover 显示操作图标：编辑 / 删除 / 移动
- 右键菜单：置顶 / 移动到...
- 底部：一个"+"按钮（新建导航项）
- 拖拽排序 + 跨分组拖拽

### 工作区

不变。

### 分组信息页

点击分组名（或分组栏图标）→ 中间栏切到该分组，同时右侧显示 group_overview 页面：
- 分组名（可编辑）
- 分组简介（可编辑）
- 该分组下所有导航项（点击直接跳转）

## 7. 顺手修：图标裁剪 QQ 逻辑

当前 M4.1 的裁剪组件问题：
- 拖出去露白底
- 缩放中心不固定
- 无缩放上下限

改为 QQ 头像逻辑：
1. 图片初始 `object-fit: cover` 填满裁剪框
2. 拖动时限制图片边缘不能进裁剪框（不露白底）
3. 缩放以裁剪框中心为基准
4. 缩放上下限：最小 = 刚好填满裁剪框，最大 = 原图分辨率
5. 实时预览（右侧或下方显示 64×64 效果）

**如果工作量太大**：先做前三项，实时预览可省。列出你的判断。
