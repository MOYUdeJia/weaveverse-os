## M5：分组系统（主）

**目标**：把左侧导航从"平铺列表"升级为"Telegram 风格分组栏"。

**交付**：
- 新增 `groups` 表
- `nav_items` 加 `group_id` 字段（外键）
- 左侧三栏布局：分组栏（48px）+ 导航项栏（240px）+ 工作区
- 分组栏 hover 展开名字
- 分组 CRUD + 分组信息页
- 导航项置顶、移动、编辑、删除
- 删除确认 + 重名检测
- 新分组自动创建"分组导览页"
- 空分组自动删除

**顺手修**（M4.1 遗留）：
- 删除导航项加确认（M4.1 遗漏）
- 图标裁剪改 QQ 头像逻辑（不露白底、有边界约束）

**不做**：特殊类型、区块优化、搜索、主题。

**技术关键点**：
- 数据库迁移：新增 `groups` 表，`nav_items` 加 `group_id`
- 已有数据：所有现有导航项迁入一个"默认分组"
- 前端：三栏布局重构（现有是两栏）

## M6：导航项类型 + 区块优化

**目标**：导航项能按用途分不同形态，区块更紧凑好用。

**交付**：
- 三种特殊类型：doc / plain / bookmarks
- 单实例扩展：music_collection / movie_collection
- 区块紧凑化
- 新块类型：code / quote / table
- 全局搜索 + 便携笔记

## M7：主题 + 音乐播放器

**交付**：
- 淡色主题（预设）
- 背景图上传（全局 + 分组）
- 音乐播放器基础版

### M7 补充（阶段 2 追加内容）

除了原计划（主题 + 音乐 + 图片库），阶段 2 顺手加：

- **搜索分层重构**：Tab 改为 全部 / 积木页 / 专页 / 系统页
  - 全部：只搜导航项名字
  - 积木页：只搜名字
  - 专页：名字 + 专页级标签
  - 系统页：只搜名字
- **专页标签系统**：专页级标签（跨页） + 页内标签（仅页内）
- **标签视觉**：蓝色发亮，`#xx ` + 空格为完整标签
- **点击标签**：跳对应搜索并过滤
- **创建菜单重构**：积木+模板合并；系统页显示全部类型（已创建置灰）
- **笔记时间戳**：右下角小字
- **系统分组置顶**：固定第一位
- **修链接悬停提示**：WebView 里不显示

## 节奏原则

1. **每个版本 1-2 个核心功能**，不贪多
2. **数据层变更单独停下确认**
3. **大版本可拆 a/b**
4. **完成后先试用再决定下一步**
5. **不提前规划超过 2 个版本**
