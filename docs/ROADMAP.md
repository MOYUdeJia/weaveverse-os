# Weaveverse OS · 开发路线图

| 阶段     | 里程碑              | 核心交付                                | 状态 |
| -------- | ------------------- | --------------------------------------- | ---- |

| M1       | 数据持久化          | SQLite + 导航 CRUD + Alembic            | ✅    |

## 各阶段详情

### M4.1：修 bug（试用后启动）
**触发条件**：M4 试用几天，攒一批问题。
**可能范围**：
- 最近阅读卡片显示百分比数字
- 单实例类型创建校验（bookshelf / vault / idea_box 等）
- 试用中发现的其他问题
- 可选：EPUB 章节资源接口（解决裂图）

**不做**：任何新功能。

---

### M5：搜索 + 便携笔记
**目标**：让数据可被快速找到和录入。

**交付**：
- 全局即时搜索（输入即时出结果，不点搜索按钮）
- 便携笔记浮层（全局快捷键呼出）
- 笔记自动分类
- M4.1 后遗留的小问题

**技术**：
- 搜索：前端模糊匹配 + 后端简单索引（不引大库）
- 快捷键：前端 `keydown` 监听

---

### M6：IDEA 栏 + 自定义 UI
**目标**：结构可以定制，点子可以管理。

**交付**：
- IDEA 栏（单实例，点子列表 + 标签）
- 自定义 UI（拖拽左侧导航布局、右侧区块顺序）
- 插件系统接口（定义契约，不实现完整生态）

**不做**：IDEA 栏的 AI 总结（等 M7 的 AI 基础）。

---

### M7：私有云 + AI
**目标**：远程访问 + AI 能力落地。

**交付**：
- 私有云（Tailscale / Cloudflare Tunnel + Passkey）
- AI 聊天助手
  - 多模型 API 切换
  - 自定义音色 / 语气
  - 自定义角色（待定）
  - 辅助管理 Weaveverse OS
  - 语音识别（识别你的音色）
- 智能语音呼叫
- 加密备份
- 密码保险箱
- 每日开屏问候
- 时间胶囊
- IDEA 栏的 AI 总结

**说明**：M7 很大，可能拆成 M7a（AI 基础）和 M7b（语音 + 私有云）。

---

### M8+：仪式感与高级创造力
**目标**：锦上添花。

**可能范围**：
- 成就系统
- 动态壁纸 / 粒子背景 / 鼠标跟随光效
- 白板 / 画布
- 灵感速记
- 多设备同步
- 移动端
- Tauri 迁移
- 主题市场

**说明**：这一阶段不锁死，随灵感调整。

---

## 节奏原则

1. **每个版本只做 1-2 个核心功能**，不贪多
2. **数据层变更（新表/迁移）单独一阶段停下确认**
3. **大版本（M2 这种）可能需要拆 a/b**
4. **每个版本完成后先试用再决定下一步**
5. **不提前规划超过 2 个版本的细节**
