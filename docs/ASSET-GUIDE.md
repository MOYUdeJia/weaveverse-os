# 主题素材怎么找、怎么放进来

应用不会替你下载图片或视频，也不会去掉水印。下面只是搜索方向。文件放在你自己的电脑上，再从设置里导入。

## 异环主题素材来源

- 官方宣传图：异环官网、官方微博
- 角色立绘：官方社交账号、Pixiv（搜索「异环」）
- 动态背景：B 站相关动态、官方 PV 里你自己截取的片段
- 推荐搜索关键词：「异环 立绘」「异环 4K」

## 赛尔号巅峰之战素材来源

- 精灵立绘：B 站「摸鱼的橙汁」动态
- 官方宣传图：赛尔号官网、官方微博
- 推荐搜索关键词：「赛尔号 精灵」「赛尔号 4K」

## 使用方法

1. 自己把素材下载到本地。
2. 打开应用，进入设置，再进入主题，打开素材库，点添加素材。
3. 选中文件，指定它用作颜色、背景、开屏还是图标。
4. 打开「异环（我的）」或「赛尔号巅峰之战（我的）」，在槽位里指向刚添加的素材。也可以先改槽位，再另存为新预设。

预设壳里已经有一套界面色。背景、开屏、图标是空的，要用你自己的文件补上。

## 注意事项

- 素材只供个人使用，不要公开分发，也不要放进安装包。
- 优先保存没有水印的原图。应用里没有去水印功能。
- 龙娘预设只带珍珠色和淡紫，不包含开机视频。
