## 第一部分：阅读器交互补全（M13.1 遗留）

### 1.1 书签段落锁定与最新提示
- **行为**：点击“加书签”进入标记模式后，无论用户选中几个字，**自动向上寻找包含该选区的 `<p>` 或 `<div>` 块级节点**，将整段作为书签范围。
- **UI**：在书签侧边栏列表的**顶部固定**一个美化的提示块：“📍 这里是最新的（最近阅读进度）”。
- **显示**：书签列表按**时间倒序**，每条显示时间戳（`YYYY-MM-DD HH:mm`）。点击书签，整段闪烁暖黄。

### 1.2 笔记气泡交互重构
- **正文内标记**：添加笔记的文字，背景浅蓝，文字加波浪下划线（`text-decoration: underline wavy`），末尾跟随一个 `💬` 图标。
- **气泡弹窗**：点击 `💬` 弹出气泡。**必须使用 `<Teleport>` 到 body**，用 `getBoundingClientRect` 计算位置，确保不被父级容器遮挡。
- **气泡功能**：
  - 展示笔记内容。
  - 提供“复制”、“编辑（变为 textarea）”、“关闭”按钮。
  - 再次点击 `💬` 或点击外部关闭，带平滑的展开/收起动画（CSS 或 GSAP）。

## 第二部分：全局时间线（Timeline）

### 2.1 页面类型与数据聚合
- **类型**：新建系统页 `timeline`（全局唯一），默认图标 ⏳。
- **聚合数据源**：
  - 收件箱的速记（Quick Notes）
  - 阅读器添加的笔记/摘抄
  - 创建的导航项
  - 完成的番茄钟

### 2.2 UI 呈现（现代时间轴）
- **垂直瀑布流**：按日期（今天、昨天、更早）分组。
- **时间轴样式**：左侧显示时间（如 `14:30`），中间有一条贯穿的竖线及事件圆点。右侧是卡片。
- **卡片内容**：类型图标（📝/📖/🍅）+ 内容摘要。点击卡片跳转到对应详情。

## 第三部分：专注番茄钟

### 3.1 全局入口与 UI
- **入口**：侧边栏底部加一个 `⏱️` 图标，或集成到音乐悬浮球右键菜单。
- **UI**：点击后出现一个小巧的浮动面板（或圆环倒计时），默认 25 分钟。
- **功能**：开始、暂停、放弃。可以挂载白噪音（调用本地音频或 API）。

### 3.2 结束逻辑
- 倒计时结束，播放提示音，弹窗“专注结束，休息一下吧”。
- 自动在“全局时间线”中写入一条记录：`🍅 完成了一次 25 分钟专注`。

## 第四部分：数据目录自定义

- **设置 → 通用 → 数据存储**：
  - 显示当前数据目录路径（`%APPDATA%\WeaveverseOS` 或开发目录）。
  - 提供“更改目录”按钮。
- **行为**：点击后选新文件夹，提示“应用将关闭，数据将迁移至新位置”。后台把当前数据复制到新目录，修改配置，重启后生效。（注意安全：先复制，验证成功再删旧数据，防止丢失）。

## 第五部分：窄屏/手机端适配与收尾

### 5.1 响应式布局（`max-width: 768px`）
- **导航栏抽屉化**：手机端默认只显示工作区。左上角出现汉堡菜单，点击滑出“分组 + 导航”抽屉，选中后自动收起。
- **设置页**：左侧分栏在手机端折叠成顶部横向滚动或下拉。
- **悬浮球**：手机端吸附到底部，不挡操作。

### 5.2 交互收尾
- 确保所有删除操作（导航项、预设、素材、标注）都有二次确认。
- 确保触摸热区 `min-height: 44px`。
