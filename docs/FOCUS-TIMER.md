# Weaveverse OS · 番茄钟独立悬浮窗设计规范

## 一、 核心定位
基于原生的系统级置顶窗口（Desktop Pet 模式），不依附于主应用界面。用户无论在全屏玩游戏还是写代码，都能随时看到倒计时。

## 二、 悬浮窗形态
1. **外观**：无边框透明小窗，包含一个圆环倒计时、任务名。
2. **置顶**：始终保持在所有窗口最前面（always_on_top=True）。
3. **拖动与隐藏**：鼠标按住可拖动；拖到屏幕边缘时，自动半隐藏（只露一条边），鼠标悬停时弹出。
4. **右键菜单**：
   - 暂停 / 继续
   - 进入全屏专注
   - 隐藏（隐藏后可通过主应用左下角或托盘重新唤起）

## 三、 全屏模式
1. 点击“进入全屏专注”后，弹出全屏无边框窗口。
2. 背景纯黑或动态壁纸，中间显示超大倒计时。
3. 支持播放 Web Audio 生成的白噪音。
4. 右键或按 Esc 可退出全屏，变回悬浮窗。

## 四、 统计与数据
悬浮窗的数据实时上报给后端，存入 `focus_sessions` 表，并在主应用左下角的“专注统计页”中呈现热力图和图表。
